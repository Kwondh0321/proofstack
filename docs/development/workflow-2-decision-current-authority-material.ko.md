# 완전한 결정 권한 관측 자료

[English](workflow-2-decision-current-authority-material.md) | [한국어](workflow-2-decision-current-authority-material.ko.md)

상태: 체크포인트 4의 선행 계약입니다. Workflow 2는 7개 중 3개 인수 완료입니다.
실제 현재 소스 수집, 비공개 인증, 보호된 원자적 저장, API/SDK 및 독립 종료 감사는 남아 있습니다.
[ADR-0043](../architecture/0043-version-complete-captured-decision-authority.md)과
[진입 감사](workflow-2-decision-entry-audit.ko.md)를 함께 읽습니다.

## 버전과 보존 자료

[0.2 자료](../../packages/contracts/src/release-decision-current-authority-material.ts)는
엄격한 기존 [0.1 자료](workflow-2-decision-authority-snapshot.ko.md)를 `base`로 보존하고 다음을 추가합니다.

- 정확한 설치/대상 선택 루트와 모든 관련 검토자 권한 루트의 census·바인딩 관측입니다.
  누락, 사용 불가, 잘못된 자료도 명시적으로 남깁니다.
- 원래 게시자·검토자의 자격 증명과 원래 바인딩, DB 정밀도의 생성·사용·폐기 시각입니다.
  나중 로그인으로 원래 자격 증명을 바꾸지 않습니다.
- 계획된 원래 요청 각각의 전체 소유 작업 그래프, 봉인된 모든 페이지와 행위자 출처 또는
  명시적 사용 불가 사유입니다. 원래 요청·작업·결정 시도·스냅샷·결과 및 주체 작성자를 연결합니다.
- 모든 보완 통제 발생입니다. 반복 객체, 반대 행동, 만료 승인을 제거하지 않으며 원래 승인 순서와
  숫자 인덱스 0–15를 유지합니다. 문자열 정렬로 10이 2보다 앞서지 않습니다.

[소스 계약](../../packages/contracts/src/release-decision-current-authority-sources.ts)은 실제 콘텐츠 관측
시각·결과와 이후 카탈로그 상태를 분리합니다. 읽지 않은 경우 사유를 남기며 관측 시각을 만들지 않습니다.
비활성/비승인 사유에는 보존된 행동·이력 근거가 필요합니다. 읽지 않았더라도 이후 카탈로그의 정확한
범위·콘텐츠·소유권을 검사합니다. 이전 검증 성공은 이후 변경·누락·폐기·만료를 지우지 않습니다.

동일한 물리적 신원·자격 증명에 서로 다른 소유자나 자료를 부여할 수 없습니다. 보존된 모든 정규화 행과
바이트는 원래 요청 예산의 하한에 포함됩니다. 실제 수집기는 실패·반복·폐기한 시도까지 동일한 원래
계량기에 부과해야 합니다. 정규화나 중복 제거는 예산을 돌려주지 않습니다. 전체 자료와 인코딩된
봉투에 각각 기존 64 MiB 상한을 적용합니다. 평문·키·위치·비공개 인증 증명은 전송하지 않습니다.

## 정규 무결성과 호환성

[0.2 인코딩](../../packages/contracts/src/release-decision-current-authority-encoding.ts)은 별도의 v2
자료·헤더·페이지 도메인을 사용합니다. 기존 2,048바이트 프레임, 페이지당 128프레임, 최대 256페이지와
512 KiB 응답 여유를 유지합니다. 기존 0.1 코드·도메인·독립 벡터의 의미와 바이트는 보존합니다.

[비공개 코덱](../../packages/core/src/release/release-decision-current-authority-snapshot.ts)은 정확한
범위·결정·입력·헤더·페이지, 도메인, 정규 바이트, UTF-8 및 해시를 검사합니다. 원래 입력, 불변 소유
정의, 논리 루트 투영 해시와 요약을 다시 계산합니다. 완전한 원래 평가에는 기존 봉인 평가의 의미 검사를
재사용하며 행위자 보고서를 원래 증거와 루트 작성자에 연결합니다. 해시만으로 비루트 행위자의 실제 신원이나
콘텐츠·자격 증명을 인증할 수 없으므로 실제 소유 소스 검증은 별도로 필요합니다.

[독립 벡터 4개](../../packages/contracts/vectors/release-decision-current-authority-snapshot-v2.json)는
JS 코덱·스키마를 가져오지 않는 Python UTF-8 JSON·hashlib·base64로 생성했습니다. 누락 원본, 합성 권한,
사용 불가 권한, 합성 승인 바인딩을 다룹니다. 실제 현재 권한 검증이나 네이티브 승인의 증거가 아닙니다.
테스트는 0.1 바이트 호환, 여러 페이지와 분할 Unicode, 바깥 해시를 다시 만든 변조도 검사합니다.

별도의 독립 메모리 모델은 합성 수집 시각의 새 요청을 만든 뒤 enqueue·봉인·결정적 계산을 수행합니다.
새 요청의 manifest와 합성 수명주기 투영을 구성하며 보관된 벡터나 네이티브 영수증은 바꾸지 않습니다.
전체 원래 그래프·페이지를 복원하되 현재 선택·신원·상위 행위자의 사용 불가는 명시적으로 유지합니다.
원래 행위자 증거를 바꾸거나 위조된 규칙 결과와 모든 소유 결과 참조를 함께 다시 해시해도 거부합니다.
이는 과거 의미 무결성 검사이며 실제 수집·인증이나 유효한 릴리스 결정이 아닙니다.

## 저장 경계와 다음 작업

[대상 소유 선택 메모리/공통 저장소](workflow-2-selection-repository.ko.md)는 소유 저장 경계의 첫 구현입니다.
네이티브 보호나 실제 현재 결정 권한을 제공하지는 않습니다.

`complete`, `observed`, `underGuards`는 보존된 데이터이며 실제 열거·비공개 인증·유지 중인 잠금의 증명이
아닙니다. 디코딩은 나중 게시 권한을 만들지 않습니다. 원래 세션의 자연 만료는 과거 자료로 남을 수 있으며
명시적 폐기·신원 변경·현재 권한과 구별해 판단해야 합니다.

다음에는 고정 소유 리더와 원래 계량기, 현재 일반/예외 승인·보완 통제 해석 및 메모리/DB 공통 검증을
완성합니다. 네이티브 작성자는 현재 마이그레이션·복구 epoch를 확인하고 신원·소스·부재 보호를 동일한
트랜잭션에서 유지한 채 불변 그래프·결정·정규 outbox를 원자적으로 저장해야 합니다. 콘텐츠·키 I/O는
보호 밖에서 수행합니다. 이후 예약·복구, 인가 우선 API/SDK, 실제 서비스 기여자 실행과 독립 종료 감사를
완성합니다. 호출자가 보낸 스냅샷·행위자 보고서나 오래된 관측 성공으로 대체할 수 없습니다.
