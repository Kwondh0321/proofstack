## 불변 선언과 정확한 소유권

[마이그레이션 0066](../../packages/postgres/migrations/0066_release_reviewer_authority_storage.sql)은
최초 루트·원본 버전·역할/그룹·명시된 관계와 충돌·근거 참조·종료 이력을 여섯 비공개 테이블에
정규화합니다. 최초 기록은 테넌트·프로젝트·환경과 설치·게이트·검토자를 고정합니다. 같은
게이트의 다른 검토자는 별도 루트를 가질 수 있지만 다른 범위로 소유권을 가져올 수 없습니다.
서로 다른 테넌트의 같은 물리 ID는 허용합니다.

정확한 범위의 외래 키, 지연된 완전성·순서 제약, 정규 바이트와 해시, 원본 시각 순서 및
정규 outbox 의도가 전체 그래프를 연결합니다. 자기 발급·해시 위조·잘못된 선행자/후속자·
인과 시각 오류·두 번째 종료·대상 재할당은 전체 실패합니다. 같은 의도의 재시도는 최초
행위자와 시각을 보존합니다. 여섯 테이블은 추가 전용이고 소유자에게도 정확한 RLS를 강제합니다.

[어댑터](../../packages/postgres/src/postgres-release-reviewer-authority-repository.ts)는 기존의
신뢰된 내부 선언 포트를 구현합니다. 합성 근거, 운영자 확인 표기, 검증·불확실·거부 상태,
관계·충돌·사유, 역할·독립 그룹과 모든 근거 참조를 보존합니다. 저장된 표기나 해시가 실제
전문성·발급자 인증·현재 근거 가용성을 증명하지 않습니다. 새 런타임 역할·기본 권한·경로·
작업·워커는 추가하지 않습니다. 역할 재설정은 복원된 오래된 비공개 접근도 회수합니다.

## 완전한 읽기와 유지되는 guard

`readPostgresReleaseReviewerTargetOnClient`는 정확한 설치·게이트·검토자 대상에서 최초 소유
루트를 도출합니다. 별도 C4 테넌트 검토자 guard가 대상·버전·종료 이력의 부재까지 보호하고
모든 삽입에 배타적 트랜잭션 guard를 강제합니다. 비공개 VOLATILE 루트 함수는 공유 guard
획득 뒤 READ COMMITTED 상태를 관측합니다. 경합은 전체 cut을 실패시키며 유리한 시점까지
재시도하지 않습니다. 이 잠금 단위는 참조 정확성 선택이고 처리량 측정은 아닙니다.

고정 16개 키셋 페이지로 모든 미래·경쟁 버전과 철회·대체 이력을 읽습니다. 검증된 최신
기록만 고르거나 호출자가 논리 루트를 선택하지 않습니다. 원본 정규 정의와 정규화 필드,
역할·그룹·선언·근거의 순서, 최초·선행자 참조, 시각과 정규 outbox를 검증합니다. 손상은
일부의 유리한 목록이나 정상 부재로 바뀌지 않습니다.

동일한 원래 서버 소유 예산에 원본 바이트와 묶인 레코드 수·반복 관측·부재를 먼저 계상합니다.
한도에 맞춘 일부 목록을 반환하지 않고, 실패를 잡아도 같은 예산은 계속 실패 상태입니다.
가짜·실패 예산으로 새 I/O를 시작할 수 없습니다. UTC 원문은 소수점 이하 최대 30자리를
보존하고 정확한 수치 순서 키는 문자열로 전송합니다. outbox DB 시간은 투영입니다.

제공 연결 함수는 호출자의 명시적 정확 범위 트랜잭션을 시작·종료·대체하지 않고 guard를
유지합니다. 편의 저장소 메서드는 반환 전에 자체 트랜잭션을 끝내므로 **반환된 목록만으로
나중에 발행할 수 없습니다.**

## 검증과 남은 경계

기존 공유 적합성 검사를 실제 DB 구현에 적용합니다. 네이티브 검사는 다중 페이지, 동일
연결·XID·savepoint, 부재·철회 경합, 범위·격리·경합 거부, 소유자 RLS, 손상과 순번 누락의
전체 롤백을 다룹니다. 실제 합성 PostgreSQL 16.15 응답을 이용한 단위 검사는 변조·예산·
실패·정리를 검증하지만 독립 SQL 오라클이나 실제 DB 실행을 대신하지 않습니다.

복구 fixture는 모든 새 테이블을 채우고 전체 원본 그래프·정규 outbox 복원을 비교한 뒤
소유 저장소 읽기와 최초 영수증 재시도를 검사합니다. 기존 체크섬·역할 재설정·복구 단언과
커버리지를 유지하며 폐기용 `proofstack_test`에서만 실행합니다.
