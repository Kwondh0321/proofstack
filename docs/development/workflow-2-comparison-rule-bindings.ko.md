# 후보 소유 비교 규칙 입력

[English](workflow-2-comparison-rule-bindings.md) |
[한국어](workflow-2-comparison-rule-bindings.ko.md)

상태: 보존된 비교 입력 연결을 구현했습니다. Workflow 2는 승인된 체크포인트 2/7이며
체크포인트 3은 미완료입니다. 이 입력은 정책 평가 결과가 아닙니다.

`capturePolicyArtifactEvidence`는 고정된 내부
[`inspectCapturedComparisonRules`](../../packages/policy-evaluation/src/capture-comparison-rules.ts)의
`comparisonRules`를 반환합니다. 정확한 요청 식별자·범위·평가 시각·루트 순서, 전체
후보·정책·비교·결과·스냅샷 본문과 원래 수신 해시, 전체 부모 참조와 원래 간선을
재검증합니다. 부재 관측에는 null 본문·참조와 유효한 manifest 관측이 필요하며
부재 기록에서 임의의 간선을 만들 수 없습니다.

## 전체 목록과 원래 규칙

기존 소유 비교 선택·계보 재현기를 검증된 보존 기록에 적용하며 저장소·객체·키를
추가 조회하지 않습니다. 전체 후보 목록과 비교 보고는 이번 호출에서 수집한 결과와
일치해야 합니다. 사용하지 않거나 읽을 수 없는 후보 결과도 유지합니다. 최신 결과를
선택하거나 읽을 수 없는 항목을 제거해 유일한 선택으로 바꾸지 않습니다.

비교를 사용하는 모든 규칙은 원래 조건·정책 위치·간선과 전체 비교 수집 결과의
인덱스를 유지합니다. 반복 규칙도 각각 보존합니다. 부재·복수·미해결 선택, 기록 사용
불가, 잘못된 계보는 명시적인 사용 불가 연결로 남습니다. 실제 없는 지표는
`metric_missing`이며 수집 증거의 변조는 부재로 처리하지 않고 실패합니다.

## 정확한 기술적 피연산자

검증된 지표는 원래 정의·결과·층의 위치와 전체 객체를 유지합니다. 역할별 표본
계수 15개, 정확한 값, 사용 불가·비교 불가 이유와 일부 역할의 보존된 값도 유지합니다.
원래 계산 정책·비교 가능성·짝짓기·최신 원본 시각과 비교·결과·양쪽 스냅샷의 전체
해시를 연결합니다.

임계값 입력은 정확한 지표 종류와 단위 일치를 기술합니다. 안전 이벤트 입력에는
이벤트 종류의 일치도 필요합니다. 비교 표본·비율 coverage는 원래 역할별 계수와
분모 선언을 유지하며 `cases`·`basis_points`를 지표의 측정 단위로 혼동하지 않습니다.
불일치 입력도 원래 증거와 명시적인 이유를 유지합니다. 수치 조건·전체 안전 점수·
승인·정책 판정은 계산하지 않습니다.

## 누적 예산과 남은 경계

검사한 전체 부모 참조, 전체 목록과 문맥 한 프레임, 모든 원래 규칙 프레임을
canonical UTF-8 개수·바이트로 계산합니다. 반복 규칙도 각각 계산합니다. 수집기는
기록 바이트와 기존 검사들이 공유하는 동일한 유한 예산에 이 비용을 더합니다.
정확한 한도는 통과하고 하나 모자라면 실패합니다. 반환된 중첩 기록은 보고서의
독립 복사본입니다.

함수는 내부용이며 공개 표면에는 보고서 타입만 추가합니다. 의존성·역할·권한·
마이그레이션·경로·worker·발행 포트를 추가하지 않습니다. 전체 상위 의미·현재 권한
의존 관계, 엄격한 봉인 스냅샷·결과 계약, 같은 열린 트랜잭션의 스냅샷·작업·fence
발행, 일곱 결정적 조건, 내구성 작업, API·SDK·복구와 독립 완료 감사가 필요합니다.
재검사 보고를 반환하기 전에 끝난 트랜잭션은 이 입력을 이용한 나중 발행을
승인하지 않습니다.
