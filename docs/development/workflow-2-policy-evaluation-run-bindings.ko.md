# 수집한 평가 실행 정의의 연결 검사

[English](workflow-2-policy-evaluation-run-bindings.md) | [한국어](workflow-2-policy-evaluation-run-bindings.ko.md)

상태: 수집한 그래프의 내부 검사에서 실행 정의를 먼저 확인한 뒤 실행 결과·집계·평가 이력으로
연결합니다. Workflow 2 세 번째 체크포인트는 미완료입니다. 이 검사는 기록된 관계이며 설치된
실행 권한, 출처 신뢰성, 정책 충족이나 릴리스 허가가 아닙니다.

## 이력 검사만으로 충분하지 않은 이유

관측 이력이 일관되어도 잘못된 평가기·오라클·기준·자격 보고서를 사용할 수 있습니다.
[스냅샷 검사](workflow-2-policy-evaluation-snapshot-bindings.ko.md)는 이제 `evaluation_run`
부모에 `run_*` 검사를 남기고, 각 실행 결과에 별도의 `run_definition` 전제를 추가합니다.
결과 이력의 일치가 실행 정의의 모순이나 누락을 없애지 않으며 집계·평가로 그대로 전달됩니다.

같은 수집에서 고정 리더가 검증한 기록과 부모에 결속된 간선만 사용합니다. 임의의 그래프를
승인하는 공개 함수, 추가 저장소 조회, 평가기·오라클 실행이나 대체 증거 검색은 없습니다.

## 검사 범위

| 관계 | 확인 내용 |
| --- | --- |
| 기준 | 정확한 기준 집합에 요청한 기준이 있고 평가기·오라클 참조가 실행의 선언과 일치하는지 확인합니다. |
| 적용 조건 | 문맥의 canonical SHA-256을 재계산하고 명시된 환경이 실행 범위를 벗어나지 않는지 확인합니다. 기존 `evaluateApplicability`로 기준 표현식을 다시 계산합니다. 미결정 결과를 적용·비적용 선언의 일치로 간주하지 않습니다. |
| 기준 게시·상태 | 적용 조건 계산 전에 기준이 게시되었는지, 참조한 상태가 같은 기준 버전을 승인하고 실행 생성 시점에 기록·유효했는지 검사합니다. 만료 경계는 제외합니다. 최신 상태 조회나 현재 권한 판정은 아닙니다. |
| 집계·출처 참조 | 집계 정책의 데이터셋·게시 시점과 기준이 선언한 출처 검토 참조 전체의 일치를 검사합니다. 참조 일치가 검토자의 권한을 증명하지 않습니다. |
| 평가기·오라클 | 해당 기준 버전을 지원하며 실행 생성 전에 게시되었고, 평가기가 실행의 정확한 오라클을 지정하는지 확인합니다. |
| 시도 한도 | 모든 시도의 시간·입력·출력·메모리 상한이 두 명세의 한도 이내인지 확인합니다. 실제 실행 강제·사용량은 별도입니다. |
| 자격 대상·사례 | 자격 보고서의 대상과 명세의 사례 집합이 일치하고, 선언된 모든 사례의 ID·종류·기대 결과를 보존하는지 검사합니다. 기준의 각 자격 사례도 정확한 fixture·기준 선택자·종류·판정으로 포함되어야 합니다. |
| 자격 선언·시각 | 보고서가 자격 충족을 선언하고 실행 생성 전 기록·완료되었으며 생성 시점이 유효 구간 안에 있는지 확인합니다. 보고서 시작 전에 대상 명세와 사례 집합이 게시되어야 합니다. 실제 역량·독립성·실행 증명은 아닙니다. |

시각은 `policyEvaluationTimestampOrderKey`로 비교하여 지원되는 모든 소수 자릿수와 오프셋을
보존합니다. 데이터베이스 커서 반올림이나 작업자 현재 시각으로 대체하지 않습니다. 사례 집합은
스키마가 보장하는 고유 fixture 버전으로 인덱싱하여 기준 사례와 전체 사례를 중첩 탐색하지 않습니다.

## 누락·출처·누적 한도

독립적으로 판단 가능한 검사는 다른 의존 기록의 누락 때문에 지워지지 않습니다. 기록이 없으면
`unavailable`, 확인된 모순이면 `mismatch`를 보존합니다. 유효한 기준 집합 안에 요청한 기준이
없으면 모순입니다. 오염·미래 기록의 원래 그래프 사유도 유지하고 저장소·내부 출처 오류는 전파합니다.

실행 보고서는 원래 전체 기록 해시와 간선 인덱스를 유지합니다. 자격 사례 집합을 참조하는 간선은
실행이 아니라 원래 자격 보고서를 부모로 유지합니다. 여러 실행이 같은 보고서·사례 집합을 쓰더라도
단일 스냅샷 검사 계수에서 매번 사용 전에 계수합니다. 결과의 전제 요약은 같은 실행 보고서를
참조하며 검사를 다시 실행하거나 계수를 초기화하지 않습니다. 기존 평가의 중첩 집계 계수도 유지합니다.

## 검증과 남은 경계

실제 메모리 저장소의 정상·모순 그래프, 두 명세의 네 가지 예산 차원, 의존 기록 누락, 누락과 모순의
공존, 원래 해시·간선, 조회 횟수·누적 한도와 소수 초 만료 경계를 테스트합니다. 같은 버전 ID의
상충하는 참조는 수집 자체에서 차단하고, 별도 도메인 단위 테스트로 참조 비교 규칙을 검증합니다.
테스트 자료는 해시 계산·게시 전에 연결하며 운영 검증 규칙을 완화하지 않습니다.

현재 기준·출처·검토자 권한, 자격 정책 등록, 실행기 설치, 아티팩트 가용성, fixture·재현 내용 의미,
독립성, 통계 구간의 수치 정확성이나 측정값의 사실성은 증명하지 않습니다. 모델·사람 평가 관계,
변경 가능한 권한·동시 변경 방어, 봉인·정책 결과·영속 작업·API/SDK·복구·종단간 승인이 남았습니다.
기존 데이터셋·재현·아티팩트·비교 보고서도 함께 검증해야 합니다. Workflow 2 완료 체크포인트는
**2/7**입니다.
