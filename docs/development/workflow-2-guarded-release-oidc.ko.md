# 같은 네이티브 연결에서 현재 OIDC 권한 재검사

[English](workflow-2-guarded-release-oidc.md) | [한국어](workflow-2-guarded-release-oidc.ko.md)

[ADR-0052](../architecture/0052-recheck-authenticated-release-oidc-on-held-clients.md)과
[진입 감사](workflow-2-decision-entry-audit.ko.md)에 따른 OIDC 구성요소입니다. Workflow 2는 3/7개
체크포인트 승인 상태이고 완전한 네이티브 결정 게시는 미완료입니다.

## 실제 인증과 같은 연결의 현재 원본

고정 함수는 실제 소유 인증기가 발급한 불투명 인증 객체와 서버의 정확한 동작·범위·요청 ID를
검사합니다. 공개 영수증이나 과거 관측으로 대체할 수 없습니다. 서비스 게시자 인증은 브라우저
원본 검사에 사용할 수 없으며 서비스 자격증명의 현재 네이티브 바인딩은 별도 미완료 사항입니다.

호출자가 보유한 READ COMMITTED 트랜잭션의 실제 테넌트·프로젝트·환경 GUC를 검사한 뒤 세션
가드를 잡고 실제 소유 바인딩을 읽습니다. 바인딩 가드까지 잡은 다음 같은 연결에서 전체 세션과
권한을 재조회하고, 그 뒤의 네이티브 6자리 시각으로 기존 소유 검증기를 적용합니다. 원래 인증
영수증·사용자·권한·범위·철회·유효기간이 맞아야 합니다. 과거 검토 보존에만 허용한 로그인 자연
만료 규칙을 새 행동 생성에 사용할 수 없습니다. 세션 시각이나 수명을 갱신하지 않습니다.

함수는 트랜잭션을 시작·커밋하거나 클라이언트·SQL 포트를 반환하지 않습니다. 반환 후에도 가드는
호출자 트랜잭션이 끝날 때까지 유지됩니다. 일부 가드를 잡은 뒤 경합한 경우를 포함한 모든 실패는
전체 롤백해야 합니다.

## 원래 예산과 남은 게시 경계

소유 바인딩·세션 조회는 선택적으로 같은 원래 요청 예산을 받아 원시 행이나 명시적 부재를 깊은
해석 전에 계상합니다. 반복 조회도 보존하고 예산을 적용한 조회 실패는 예산을 계속 실패 상태로
만듭니다. 예산을 생략한 기존 호출의 오류 동작은 유지합니다. 고정 합성은 실제 문맥·가드 결과·
DB 시각·권한/세션 투영도 계상합니다. 정상 구성요소는 9개 기록과 승인 기록 0개를 사용하며
바이트는 실제 전체 관측에 따릅니다. 정확한 한계와 한 단위 부족을 검사합니다.

이 구성요소가 유효해도 전체 결정 게시 권한은 아닙니다. 실제 설치·검토자 권한·주체 독립성,
전체 선택·원래/현재 원본·부재 closure, migration·복구 epoch·유효기간과 나머지 모든 가드를
원자 그래프·결정·정규 outbox 쓰기까지 검증·유지해야 합니다. 가드를 놓고 반환 보고서로 나중에
게시할 수 없습니다. DB 역할·권한·공개 API·SDK·워커는 추가하지 않습니다.

집중 검사는 실제 생성한 세션·CSRF와 불투명 인증, 가상 DB 전송을 사용합니다. 네이티브 검사는
일회성 PostgreSQL의 실제 OIDC 저장소·인증과 같은 backend/transaction/savepoint, 인증 뒤 권한·
세션 철회, 실제 blocking PID 경합과 세 테넌트의 인증 격리를 다룹니다. 기존 전역 OIDC 바인딩
ID의 충돌 거부 제약은 유지합니다. 타 테넌트 인증 객체의 실제 요청 ID도 함께 전달해 범위 자체의
거부를 검사합니다. 합성 사용자와 fixture
권한을 실제 제공자 로그인·검토자 전문성·운영 역할 승인으로 주장하지 않습니다.
