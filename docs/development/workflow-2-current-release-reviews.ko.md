## 원래 행위와 현재 자격

검토자 권한의 원래 버전·predecessor·successor·철회·교체 이력을 모두 검사합니다.
누락은 미확정, 중복·경쟁 버전은 충돌로 보존합니다. 역순 256개 버전 체인도 재귀 없이
검사합니다. 실제 reader는 설치·gate·검토자별 logical root와 전체 열거·누락 guard를 별도로
확인해야 합니다. 외부에서 준 `complete` 표시는 그 증명이 아닙니다.

원래 OIDC 사용자 영수증과 현재 grant·capability·범위·네이티브 세션을 연결합니다.
권한은 원래 검토 시점과 현재 시점 모두 유효해야 합니다. 세션 실제 생성 전이나 절대 만료
이후의 검토는 인정하지 않습니다. 자연스러운 옛 로그인 만료만으로 이미 기록된 검토를
지우지는 않지만 명시적 철회·현재 grant 변경은 적용합니다. 새 행위에는 살아 있는 실제
인증이 계속 필요합니다.

정책 작성자는 제외합니다. 정책이 허용한 후보 작성자는 일반 자리에만 들어갈 수 있고
독립된 사람의 증인이 되지는 못합니다. 예외는 후보 작성자와 원래 평가자도 제외하며
평가자 출처가 없으면 미확정입니다. 작성자·평가자 목록은 실제 원본에서 유도해야 합니다.
`synthetic_reference` 표시는 실제 전문성 인증으로 바꾸지 않습니다.

## 빠짐없는 일반 승인 정족수

정확한 불변 subject와 일반 승인 kind 전체를 열거하고 원래 행위자 연결을 보존합니다.
정규 해시·범위·시각과 명시적인 교체·철회를 검증합니다. 유리한 최신 승인만 고르거나
다른 subject 자료를 조용히 빼지 않습니다. 같은 검토자는 자기의 정확한 기존 행위만
교체할 수 있습니다. 새 철회 영수증으로 원래 승인 영수증을 바꾸지 않습니다.

만료·철회·교체된 행위도 남깁니다. 유효한 반대·상향 검토 요청은 정족수 만족을 막고,
기권은 사람 수에 더하지 않습니다. 중복·갈라진 이력, 같은 사람의 동시 활성 행위,
선언한 이해충돌과 미검증 조건도 긍정 투표 뒤로 숨기지 않습니다.

모든 승인·행위자·권한 이력·grant·세션 관측을 원래의 하나의 예산에 청구합니다.
같은 물리 바인딩·자격 증명·권한·이력 레코드는 반복 관측에서도 같아야 합니다.
다른 principal 표기로 같은 세션 ID를 빌리거나, 유리한 최신 관측만 남길 수 없습니다.

기존 512명 한도를 원래 승인 조회 계약의 4,096건과 맞췄습니다. 독립적인 작은 그래프
전수 oracle은 유지하며 4,096개 승인 전체·관측 20,480개 검사에서도 마지막 필수 사람
그룹을 놓치지 않습니다. 선택한 증인은 정확한 승인 참조·사람·그룹·출처를 남기고,
유효기간은 선택한 승인과 권한 중 가장 이른 만료를 넘지 않습니다.

## 남은 경계

이 결과는 캡처 자료의 계산이며 실제 인증·현재 소유 소스·원자적 게시 권한이 아닙니다.
도우미는 트랜잭션을 유지하지 않습니다. 외부의 목록·문맥·matched 보고서를 승인 근거로
받아서는 안 됩니다. 실제 인증된 생성·철회도 별도의 저장·권한 경계입니다.

완전한 버전 계약과 행위자 출처, 실제 소유 reader, 예외·보상 통제 검증, 메모리 공통 검사,
네이티브 신원·누락 guard와 그래프/결정/outbox 원자적 게시, 예약·복구·API/SDK·실서비스
기여자 검증과 종료 감사를 이어서 닫아야 합니다. 체크포인트 4는 아직 완료가 아닙니다.
