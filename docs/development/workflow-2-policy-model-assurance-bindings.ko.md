# 수집한 모델·사람 평가 증거의 연결 검사

[English](workflow-2-policy-model-assurance-bindings.md) | [한국어](workflow-2-policy-model-assurance-bindings.ko.md)

상태: 기록된 모델 평가 확장과 그 전제를 검사하는 내부 구현입니다. Workflow 2의 세 번째
체크포인트는 미완료이며 승인된 체크포인트는 **2/7**입니다. 적격성·승인·정책 결과·봉인된
스냅샷·릴리스 결정을 발급하지 않습니다.

## 연결 위치와 시간 기준

`capturePolicyRecordGraph`는 기존 평가 스냅샷 검사 후 `modelAssurance` 보고서를 반환합니다.
같은 수집에서 검증된 기록·정확한 부모 간선·평가 보고서만 사용하며 추가 저장소 조회, 모델 실행,
검색, 아티팩트 내용 읽기나 게시를 하지 않습니다. 패키지 루트에는 보고서 타입만 공개하고 임의의
그래프를 승인하는 검사 함수는 공개하지 않습니다.

각 `model_assurance_assessment`의 전제에 대해 `matched`, `mismatch`, `unavailable`을 남깁니다.
원래 전체 기록 해시와 중첩된 자격·관측·검토자 독립성 간선 인덱스를 보존합니다. 평가 자체를 읽을
수 없으면 `unavailableParents`에 리더의 원래 관측을 유지합니다. 전체 성공·적격성 필드는 없습니다.

시간 기준은 요청의 `evaluationTime`이나 작업자 현재 시각이 아니라 평가에 기록된 **`evaluatedAt`**입니다.
나중에 수집했다는 이유만으로 과거의 일관된 평가 이력을 잘못된 이력으로 바꾸지 않습니다.
현재 정책 시점의 유효성과 권한은 별도로 검사해야 합니다.

모델·사람 평가 계약은 UTC 밀리초 시각을 사용합니다. 기존 자격·보정·블라인드·비평·정족수 함수를
검증된 평가 시각으로 호출하며, 더 정밀한 정책 시각을 잘라 넣지 않습니다. 추가 시간 비교는
`policyEvaluationTimestampOrderKey`를 사용합니다. 의존 기록은 평가 시점 이전에 기록되어야 하고,
평가 시점은 자신의 수신 시점 이후일 수 없습니다. 선언한 유효기간은 검사한 전제보다 길 수 없으며
자격·검토 만료 경계는 제외합니다. 수집 리더의 요청 시점 제한과 미래 기록의 불가 상태도 별도로 유지합니다.

## 검사 내용

| 영역 | 확인 내용 |
| --- | --- |
| 기반 평가 | 정확한 적격성·기록된 출처 최신성·위험 등급·기존 실행 정의 및 평가 이력 검사 결과를 연결합니다. 모순이나 누락을 성공으로 바꾸지 않습니다. |
| 비모델 증거 | 선택된 관측·오라클이 비어 있지 않고, 기반 평가의 정확한 관측과 해당 실행의 오라클에 연결되는지 확인합니다. |
| 주 평가기·비평가 자격 | 정확한 시험 집합·프로필·독립성·보정·블라인드 계획에 기존 자격 판정을 적용합니다. 기반 자격의 상태·유효성, 보정·사례 집합 참조, 평가기·프로필·지원 기준도 검사합니다. |
| 보정 | 기반 집계 데이터셋, 기준, 평가기, 범위, 위험 등급, 기록된 언어·작업·모집단에 대한 호환성을 검사합니다. 해시 일치만으로 사용 불가·분포 변화 상태를 통과시키지 않습니다. |
| 블라인드 | 기존 계획·결과 검사로 시드·표현·시도 구성·실패·불일치를 확인하고, 완료 시도의 정확한 관측 판정과 기록 순서를 검사합니다. 실패 시도를 버리지 않습니다. |
| 평가 연결 | 주 평가의 계획·보고서·시험 집합 간 평가기·프로필·독립성·보정 참조, 검토 프로토콜의 위험·기준 범위를 검사합니다. |
| 독립 비평 | 기존 독립성·범위 검사, 지지하는 비평 결과, 선택 관측과 비평가 자격·보정의 정확한 연결을 확인합니다. |
| 사람 검토 | 기존 유효 검토 이력의 정족수·역할·증거·시간·이해 충돌·독립 집단·대체 관계를 적용합니다. 각 검토는 기반 평가와 선택 관측·비평을 포함해야 합니다. |
| 선언과 유효기간 | 비적격 선언을 충족하지 못한 전제로 보존하고 모델·프로토콜·검토·독립성 기록으로 유효기간 상한을 검사합니다. 모든 저장 사유나 최대 유효기간을 재구성하지는 않습니다. |

이 검사는 필요한 전제의 충족 여부를 확인합니다. 정직하게 작성된 비적격 평가도 `mismatch`를
가질 수 있으며, 이는 전제 미충족이지 곧바로 기록 위조의 증거는 아닙니다.

## 누락과 과거 검토의 대체

확인 가능한 모순은 다른 기록의 누락 때문에 사라지지 않습니다. 자격 미충족 보고서와 현재 유효한
반대 검토 등이 그 예입니다. 일부 사람 독립성 기록이 없더라도 기존 정족수 함수가 독립적으로 판단할
수 있는 반대·절차 실패는 보존합니다. 누락된 독립성 선언 때문에 생긴 독립성·집단 수 부족만으로는
그 선언이 잘못됐다고 확정하지 않으며 `unavailable`을 유지합니다.

반대 의견 판정 전에 기존 함수의 정확한 대체 규칙을 적용합니다. 같은 검토자의 적법한 후속 검토가
과거 반대 의견을 대체했다면 과거 의견을 계속 거부권으로 세지 않습니다. 두 기록과 사용 간선은
모두 보존합니다. 선택된 검토 기록 자체가 없으면 어떤 검토가 유효한지 안전하게 재구성할 수 없습니다.

저장소 예외, 부모 해시 불일치, 중복 간선, 내부 대상 노드 누락 같은 출처 오류는 수집을 중단시킵니다.
이를 증거 불가 상태로 꾸미지 않습니다.

## 한도와 검증

하나의 참조 발생 횟수·canonical 참조 바이트 계수로 모든 평가 부모를 검사합니다. 중첩·공유 기록도
매번 사용 전에 계수합니다. 정족수 함수에 전달할 독립성 기록을 중복 제거하더라도 이미 계수한
발생과 원래 간선은 사라지지 않습니다. 기존 평가 보고서를 재사용하며 한도를 초기화해 재계산하지
않습니다. 배열·문자열은 소유 스키마로 제한됩니다. 이 계수는 CPU 시간이나 모든 스칼라 비교·파싱
횟수의 측정치가 아니며 수집·아티팩트 전송 계수와도 구별됩니다.

테스트는 연결·재해시한 기록을 실제 메모리 평가·모델 평가·릴리스 후보 저장소에 게시합니다.
정상 연결, 스키마가 허용하는 기록 간 모순, 모델·비모델 전제 누락, 수신 시점 제한, 저장소 오류,
과거 반대 의견 대체, 밀리초 만료 경계, 여러 평가의 공유 증거 계수, 정확한 한도, 원래 출처와
방어적 복사를 확인합니다. 별도 내부 검사로 그래프 구조 훼손 시 중단도 확인합니다. 테스트의
무관한 상위 루트는 불가 상태로 남으며 전체 그래프의 정책 승인을 주장하지 않습니다.

## 남은 작업

실제 공급자 실행, 모델 역량, 검토자 전문성·독립성의 진실성, 아티팩트·측정값의 사실성,
보정 지표의 수치 재계산, 현재 출처·설치 권한이나 정책 시점 적격성은 증명하지 않습니다.
데이터셋·재현·비교·아티팩트·평가 보고서를 누락·모순 보존 하에 통합해야 합니다.
변경 가능한 권한과 동시 변경 방어, 입력 봉인, 결정론적 정책 결과, 영속 작업, API/SDK,
복구와 종단 간 체크포인트 승인은 아직 남아 있습니다.
