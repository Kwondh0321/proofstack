# 후보 소유 아티팩트 규칙 연결

[English](workflow-2-artifact-rule-bindings.md) |
[한국어](workflow-2-artifact-rule-bindings.ko.md)

상태: 보존된 입력 출처 연결 구현. Workflow 2 체크포인트 3은 미완료이며 승인 수는 2/7입니다.
이 보고는 정책 판정이나 입력 봉인이 아닙니다.

`capturePolicyArtifactEvidence`의 `artifactRules`는 고정 내부
[`inspectCapturedArtifactRules`](../../packages/policy-evaluation/src/capture-artifact-rules.ts)에서
생성합니다. 요청의 정확한 후보·정책 전체 본문, 원래 수신 기록·해시, 한도 내 부모 참조를
다시 검증한 뒤 역할을 해석합니다. 저장소·객체·키·네트워크 조회를 추가하지 않습니다.
패키지는 보고 타입만 공개하며 호출자가 만든 임의 그래프 검사 함수나 계산된 정책 결과를
제출하는 경로를 공개하지 않습니다.

## 전체 후보 선언과 원래 규칙 참조

두 루트의 정확한 참조와 전체 기록 해시를 보존합니다. `members`는 미사용 요소를 포함해
후보의 모든 빌드 아티팩트와 런타임 요소를 원래 배열 순서로 남깁니다. 각 아티팩트 설명자는
원래 후보 edge와 실제 권한 검사를 거친 캡처 인덱스에 연결됩니다. 캡처 범위·의미 평가 시각·
설명자·카탈로그 관측 및 검증된 평문 해시·크기는 서로 일치해야 합니다.

모든 `artifact_required` 규칙은 원래 정책 순서, predicate, 규칙 인덱스, 정책 edge를 보존합니다.
요소 선택은 정확한 kind와 role을 사용합니다.

- `build_artifact`: 후보의 빌드 아티팩트 역할.
- `prompt`와 `tool_contract`: 해당 런타임 요소의 종류와 역할.
- `model_resolution`: 모델 역할에 기록된 정확한 `resolutionEvidence`.

후보의 기존 스키마가 중복 요소 식별자를 거부합니다. 역할이 없으면 원래 명시적 omission을
별도로 보존하며 설명자를 만들어내거나 그래프의 비슷한 이름을 대신 조회하지 않습니다.
별칭만 가진 모델은 존재하는 요소이며 `model_alias`와 원래 선언을 보존합니다. 해결된 버전
증거용 아티팩트나 캡처 인덱스를 만들어내지 않습니다.

같은 요소를 사용하는 반복 규칙도 각각 남깁니다. 미디어 타입·분류 제한은 원래 predicate이며
바이트 검증만으로 제한 충족을 판정하지 않습니다. 요소는 있지만 바이트가 없거나 만료·삭제·
무결성 실패인 경우와 요소 자체가 없는 경우를 구분합니다. 소유권은 원래 캡처에 남으며 일반
후보 아티팩트에 기록된 fixture 전용 소유권 조건을 적용하지 않습니다. 일부 카탈로그 필드로
비공개 전체 기록 해시를 다시 계산하거나 대체하지 않습니다.

## 누적 한도와 남은 범위

전체 부모 참조, 각 후보 요소와 반복 규칙 사용을 동일 호출의 참조 개수·정규 UTF-8 바이트
한도에 합산합니다. 실제 기록 바이트와 참조 바이트는 수집 바이트 제한을 공유합니다. 정확한
한도는 통과하고 한 개·한 바이트 부족하면 부분 보고 없이 실패합니다. 루트·edge·캡처 출처
손상, 중복 캡처, 다른 범위·시각·설명자, 모순된 검증 바이트도 전체 실패합니다. 반환 배열·
선언·omission은 독립된 복사본입니다.

입력 연결만 구현합니다. 완전한 의미·현재 권한·누락 기록의 의존 관계, 봉인된 타입별 입력,
동일 트랜잭션의 snapshot/job/fence 원자적 발행, 결정론적 predicate, 영속 작업자, API/SDK,
복구와 독립 exit audit는 남아 있습니다. 소스 재검사 보고는 트랜잭션 종료 뒤 반환하므로
이 인덱스가 해제된 guard를 대신하거나 이후 발행을 승인하지 않습니다.
