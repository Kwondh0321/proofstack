## 신뢰된 저장 포트와 원래 재시도

[저장소 포트](../../packages/core/src/release/release-approval-repository.ts)는 서버 소유 정규 기록을 받습니다.
공개 raw-record POST나 비공개 인증 증명이 아닙니다. 실제 서비스/네이티브 경계는 조회·재시도·새 게시 전에
현재 행위자를 인증·인가하고 전체 상위 주체를 다시 도출해야 합니다. 공개 의도로 검토자·권한·세션·영수증·
DB 시각이나 계산 결과를 지정할 수 없습니다.

[메모리 구현](../../packages/core/src/testing/memory-release-approval-repository.ts)은 정규 해시를 검사합니다.
재시도는 정확한 의도와 검토자 principal을 비교하며 기록 스키마는 user/OIDC 영수증을 요구합니다.
새 세션·요청·현재 권한 버전·시각으로 동일한 의도를 제안해도 최초 기록 전체를 반환합니다. 원래 권한·
인증 영수증·기록 시각·만료·해시는 바뀌지 않습니다. 폐기 후 같은 재시도도 원래 기록과 폐기 이력을
유지하며 승인을 되살리지 않습니다. 다른 검토자나 변경된 의도는 충돌하며 새 행동·유효 기간은 새 ID가 필요합니다.

이 포트는 유효한 기록을 받지만 실제 현재 시각이나 인증을 제공하지 않습니다. 향후 인증된 재시도 경로는
만료된 원래 행동을 읽는 경우에도 새 영수증을 만들기 전에 보존된 의도를 비교해야 합니다. 네이티브 새
행동은 실제 현재 인증·DB 시각에 연결해야 하며 과거 영수증 반환은 신선한 게시 권한이 아닙니다.

## 인과 이력과 전체 읽기

대체는 정확한 선행 해시, 같은 검토자·종류·전체 주체와 선행 이후의 DB 정밀도 시각을 요구합니다.
한 선행 행동에 후속 행동은 하나이며 동시 동일 재시도는 한 번만 생성되고 경쟁 후속은 부분 생성 없이
충돌합니다. 반대·기권·에스컬레이션과 미해결 선언도 보존합니다.

폐기는 원래 검토자·정확한 행동과 별도 OIDC 영수증·인과 시각을 요구합니다. 새 로그인으로 자기 행동을
폐기해도 원래 승인 영수증은 바꾸지 않습니다. 동일 폐기 의도는 최초 이벤트를 반환하며 변경된 의도나
두 번째 폐기는 충돌합니다. 대체·폐기는 원래 평가 결과나 승인 기록을 수정하지 않습니다. 시각은 Date로
반올림하지 않습니다.

정확한 테넌트·프로젝트·환경 밖에서는 null을 반환합니다. 전체 읽기는 소유 원본에서 도출한 선택/대상·
후보·정책·요청/작업/스냅샷/결과·규칙 주체와 일반 승인/규칙 예외 종류를 받습니다. 호출자가 고른 행동 목록,
현재 행동 필터나 최신 조회로 반대·만료·조건·충돌·대체·폐기를 숨기지 않습니다. 두 종류는 분리되며
어느 조회도 승인이나 면제를 만들어 내지 않습니다.

전체 행·반복 관계 읽기는 원래 행·바이트·승인 계량기를 사용합니다. 정확한 한도는 통과하고 한 단위 부족은
전체 실패입니다. 실패를 잡아도 수집은 계속할 수 없습니다. 물리 주체·후속·폐기 인덱스와 슬롯·정규 해시·
인과 이력을 검사하며 손상은 부재나 유리한 일부 목록이 되지 않습니다. 반환 자료는 내부 상태와 분리됩니다.

## 검증과 남은 경계

[공통 사례](../../packages/core/src/testing/release-approval-repository-conformance.ts)는 원래 재시도,
모든 행동, 종류·주체·범위, 세 테넌트 충돌 후 재조회, 계보·동시 후속·폐기·복사·예산을 검사합니다.
[메모리 손상 사례](../../packages/core/src/testing/memory-release-approval-repository.test.ts)는 인덱스·
슬롯·해시·비 OIDC 입력·시각·잡힌 실패를 검사합니다. 자료는 합성 선언·영수증이며 실제 사용자 인증이나
PostgreSQL 어댑터 실행의 증거가 아닙니다.

메모리는 단일 프로세스 동기 copy-on-write입니다. 실제 발급자·검토자·게시자 인증, 원래 그래프·행위자·
현재 소스 조합, 예외·보완 통제, 네이티브 전용 역할과 유지 중인 신원·소스·부재 보호, 그래프·결정·outbox
원자적 저장, 예약·복구, 제한된 API/SDK, 실제 기여자 실행과 독립 종료 감사는 남아 있습니다.
