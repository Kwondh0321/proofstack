# 부모 기록에 결속된 정책 평가 선택자 해석

[English](workflow-2-policy-evaluation-selector-reader.md) |
[한국어](workflow-2-policy-evaluation-selector-reader.ko.md)

상태: 단일 참조 출현의 수집 경계 구현. 재귀 그래프 수집·아티팩트 원문·권한 관찰·스냅샷
봉인·정책 평가·체크포인트 완료는 미완료입니다. 출처 44종 목록과 로드맵 완료 개수는 그대로입니다.

## 별도 경계가 필요한 이유

기준은 평가기·오라클이 지원 기준 버전을 선언한 뒤 그 정의 해시를 참조할 수 있습니다.
모델 평가기는 먼저 발행된 프로필의 정확한 해시를 포함합니다. 이러한 순환 해시를 피하기
위한 선택자에 임의 해시를 채우거나 최신 버전을 대신 조회하면 발행 경계를 무너뜨립니다.
비교 이전 버전은 논리적 비교 ID가 없고 실행 결과는 실행 ID만 보존합니다.

[`readPolicyEvaluationSelector`](../../packages/core/src/policy/policy-evaluation-selector-reader.ts)는
정확한 부모 참조·관측 기록, 범위, 의미적 평가 시간, 출현 포인터와 유한한 부모 참조 한도를
받습니다. 호출자가 고른 자식 선택자·해시·검증기·URL·권한 덮어쓰기·최신 버전 조회는 받지 않습니다.

## 자식 조회 전에 부모 검증

부모를 읽기 전에 입력을 복사하고, 고정 검사기와 열거기로 스키마·정의 해시·범위·참조 필드·
원래 수신 시각·전체 기록 관측 해시를 재검사합니다. 정의 해시가 같아도 수신 시각만 바꾼 기록은
기존 관측을 대체할 수 없습니다. 선택한 참조 하나만 보더라도 부모의 전체 참조 목록이 개수와
canonical UTF-8 바이트 한도를 통과해야 합니다. 조기 반환이나 목록 자르기로 우회하지 않습니다.

실제 열거된 정확한 포인터의 지원 선택자만 조회합니다. 같은 선택자가 다른 위치에 반복되면
각각 보존하며 10 이상의 배열 인덱스도 그대로 유지합니다. 조회는 고정 포트로 한 번만 수행하고
포트에 넘기는 범위와 반환 기록을 복사합니다. 이 검사는 인증이 아니며, 신뢰된 수집 계층이
부모와 저장소 권한을 제공해야 합니다.

| 출현 | 정확한 조회 | 추가 관계 검증 |
| --- | --- | --- |
| `criterion_selector` | 기준 집합 버전 ID로 조회 | 논리적 집합 ID·버전·해당 기준의 실제 포함 여부 |
| `model_evaluator_selector` | 모델 평가기 버전 ID로 조회 | 평가기 ID·버전 및 부모 프로필로 돌아오는 정확한 세 필드 |
| `evaluation_run_identity` | 실행 ID로 조회 | 실행 ID 일치; 관측·결과 재계산은 별도 그래프 의무 |
| `comparison_predecessor` | 이전 비교 버전 ID로 조회 | 선언한 버전·해시와 부모의 논리적 비교 계열 일치 |

기준 포함 검증은 그 기준이 이 평가기를 선택했다거나 승인·적용 가능·정확하다는 뜻이 아닙니다.
모델 프로필과 평가기의 역참조는 정의 해시 순환 없이 존재하는 정상적인 논리적 그래프 순환입니다.
후속 수집은 이 연결을 보존하고 재방문 한도를 관리해야 하며 모든 역참조를 거부하거나 무한
재귀해서는 안 됩니다. 전체 충돌·순서·이력·누적 한도 검증은 남아 있습니다.

## 결과와 실패 구분

항상 부모 참조·전체 기록 해시와 정확한 출현을 반환합니다. `resolved`는 검증된 자식 본문,
그 본문에서 얻은 정확한 참조, 수신 정보까지 포함하는 전체 기록 SHA-256을 추가합니다.
고정 도메인 검증기가 스키마·정의 해시를 검사하고, 기존 검사기가 테넌트·프로젝트·환경 범위와
원래 수신 시각의 전체 정밀도 평가 시간 경계를 확인합니다.

`missing`은 포트가 `null`을 반환한 경우입니다. `unavailable`은 `record_invalid`,
`reference_mismatch`, `lineage_mismatch`, `not_yet_available`을 구분합니다. 두 결과의
`evidence`는 `null`입니다. 해시 없는 누락 선택자는 해시를 지어내 매니페스트 항목으로 만들지
않고 미해결 수집 목록에 남겨야 합니다. 다른 버전 재시도나 성공한 빈 의존 목록으로 바꾸지 않습니다.

잘못된 입력·미지원 또는 없는 선택자 위치는 `PolicyEvaluationSelectorReadInputError`, 부모
재검사·충돌·한도 실패는 기존 `PolicyEvaluationEvidenceReferenceError`입니다. 저장소가 던진
도메인 오류를 포함해 포트 예외는 그대로 전파하며 장애를 누락·손상 기록으로 위장하지 않습니다.

## 검증과 남은 연결 작업

[테스트](../../packages/core/src/policy/policy-evaluation-selector-reader.test.ts)는 실제 메모리
저장소로 부모 8종·조회 4종을 확인하고, 독립 참조 투영·전체 해시·정확한 조회·누락·손상·
ID와 범위 대체·기준 포함·프로필 상호 참조·다른 비교 계열·시각 경계·부모 대체·전체 참조 한도·
반복 출현·접근자 및 비동기 호출 중 변경 격리를 검증합니다. 모델 벡터가 선언한 추가 기준
집합을 별도로 보존하며 이미 발행한 평가기·프로필 쌍을 다시 쓰지 않습니다.

이 함수는 부모 하나의 참조 열거와 자식 하나의 조회이며 재귀 수집기나 영속 워커가 아닙니다.
후속 수집 계층은 누적 조회·바이트·시간·시도·식별자를 관리하고 모든 하위 기록·실제 아티팩트
원문·변경 가능한 권한 및 생명주기 버전을 검증한 뒤 완전한 스냅샷을 독립적으로 도출·봉인해야
합니다. 자격 정책·설치 구현·트레이스·프로토콜/프로필 선언·아티팩트 내부 그래프에는 각각의
소유 권한이 필요합니다. 평가기 실행·정책 충족·사람의 승인·릴리스 권한을 제공하지 않습니다.
