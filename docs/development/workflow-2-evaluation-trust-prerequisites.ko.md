# 정책 평가 시각의 보존된 평가 신뢰 전제조건

[English](workflow-2-evaluation-trust-prerequisites.md) | [한국어](workflow-2-evaluation-trust-prerequisites.ko.md)

상태: 요청에서 파생한 전제조건 관측. Workflow 2는 승인된 체크포인트 2/7이며 전체 권한 closure,
입력 봉인과 checkpoint 3은 미완료입니다.

`capturePolicyArtifactEvidence`는 이제 `evaluationTrust`를 함께 반환합니다. 내부의 고정된 검사는
각 평가 실행의 원래 기준 집합·상태·평가자 및 oracle 자격 보고서에서 출처·검토·검토자 자격,
자격 대상·픽스처 집합과 실제 보존 파일 관측을 따라갑니다. 실행에 보존된 `createdByPrincipalId`와
적용 맥락을 사용하며 파일 조회자·정책 요청자·후속 worker가 이를 대체하지 않습니다.

`evaluatePolicyCriteriaTrust`는 소유 도메인의 기존 출처·유효 기간·범위·충돌·독립성·자격·파일
가용성 규칙을 요청의 정밀한 UTC 시각에 적용합니다. 기존 서비스의 `evaluateCriteriaTrust`와
밀리초 `evaluatedAt` 응답은 유지하고 새 내부 결과는 `evaluationTime`을 명시합니다.
의미적 유효 기간을 DB 커서 정밀도로 반올림하지 않습니다.
[시각 정밀도 수정](criteria-trust-time-integrity-audit.ko.md)을 참조하세요.

각 실행은 정확한 출처·전체 기록 해시·원래 의존 간선·파일 관측 인덱스를 보존합니다. 읽을 수 없는
실행은 `unavailableParents`, 기준 집합 부재는 `criterion_set_unavailable`로 표시합니다.
원래 기준 집합 전체를 계산에 넘기므로 선택되지 않은 다른 주체의 자격 의무도 사라지지 않습니다.
범위를 줄여 다시 해시하거나 다른 그래프의 유리한 보고서·최신 기록을 선택하지 않습니다.

반복 의존성과 파일 요구는 사용마다 요청의 누적 참조·바이트 한도에 포함합니다. 순수 계산을 위한
중복 제거는 원래 출현을 기록하고 계측한 뒤에만 수행합니다. 부모·자식·참조의 해시 변경, 파일의
범위·시각·참조 대체, 관측 위치 누락과 모순된 가용성은 거절합니다. 이 검사는 호출 내부에서 이미
검증한 그래프를 사용하며 공개 API가 사용자 작성 그래프를 받는 기능은 없습니다.

새 저장소·오브젝트·네트워크 조회, 실행, 역할, 권한이나 마이그레이션은 추가하지 않습니다.
선택적인 출처 재검사 트랜잭션 전에 전제조건을 계산하고 누적 한도를 적용합니다.

`inspected`는 보존된 전제조건을 계산했다는 뜻입니다. 소유 신뢰 알고리즘의 상태·사유와 그래프의
정확한 부재·이용 불가 관측을 함께 유지합니다. 자격 대상이 없어 기존 알고리즘이 참조 불일치도
보고하더라도, 그래프의 부재가 정책 위반의 증명으로 바뀌지는 않습니다. 후속 규칙 투영은 가용성과
실행 정의·재현·후보 계보·모델 및 인간 근거·정책·변경 이력·파일 귀속 검사를 함께 사용해야 합니다.

`eligible`도 출처의 사실성, 현재 논리 루트 등록, 전체 상태·후속 이력, 실제 실행 권한, 인간 승인,
정책 충족이나 발행 권한을 증명하지 않습니다. 정확한 과거 승인 기록 하나로 후속 철회가 없다고
판단할 수 없습니다. 현재 DB guard는 파일과 정책 버전만 보호하며 읽기 전용 재검사는 반환 전에
종료됩니다. 전체 closure와 같은 트랜잭션의 snapshot/job/fence 발행 등
[남은 진입 요구사항](workflow-2-policy-evaluation-entry-audit.ko.md)을 계속 구현·검증해야 합니다.

테스트는 실제 메모리 저장소와 인증 암호화를 합성 콘텐츠에 적용합니다. 원래 주체·맥락, 읽을 수
없는 파일, 누락 기록, 정밀 시간 경계, 반복 보고서, 출처 변조와 누적 한도의 정확한 경계·하나 부족한
경계를 검사합니다. 다른 영역의 의도적 부재도 유지하며 완전한 출시 흐름이나 외부 출처 권한을
증명했다고 주장하지 않습니다.
