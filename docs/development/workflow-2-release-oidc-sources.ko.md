# 릴리스 결정을 위한 네이티브 OIDC 원본 관측

[English](workflow-2-release-oidc-sources.md) | [한국어](workflow-2-release-oidc-sources.ko.md)

이 선행 구현은 제공된 DB 클라이언트에서 비밀 값 없이 OIDC 원본을 읽고 기존 쓰기 경로에
필수 가드를 추가합니다. 체크포인트 4는 미완료입니다.
[ADR-0047](../architecture/0047-guard-native-oidc-source-observations.md)과
[진입 감사](workflow-2-decision-entry-audit.ko.md)의 권한 경계를 유지합니다.

## 원본 조회와 시간

바인딩 조회는 정확한 테넌트·바인딩 ID의 권한, 역할, 리소스 범위와 비활성 상태를 보존합니다.
authorization_version은 그대로이며 updatedAt은 실제 권한 수정 시각과 비활성화 시각 중
나중 값입니다. 비활성화가 새 권한 버전을 만들었다고 처리하지 않습니다. 역할·권한은 정렬하되
중복을 제거하지 않아 잘못된 원본을 스키마가 거부합니다.

세션 조회는 정확한 기존 세션과 바인딩에서 유도한 소유자를 읽습니다. 만료·철회·사용 이력을
남기며 lastUsedAt, idleExpiresAt, useCount를 갱신하지 않습니다. 부모가 없거나 잘못되면
무결성 오류이며 세션 부재나 새 로그인으로 바꾸지 않습니다. 네이티브 UTC 시간을 소수 여섯
자리로 읽어 Date 변환의 밀리초 절삭을 피합니다. 기존 인증 영수증 계약은 변경하지 않습니다.

두 조회는 제공된 클라이언트에서 SELECT 한 번만 실행합니다. 쿠키·CSRF 다이제스트, issuer,
subject는 선택하지 않으며 실제 인증이나 CSRF 검증도 수행하지 않습니다. 원본은 테넌트 단위
식별자이므로 프로젝트·환경은 호출자의 정확한 범위 문맥이고, 실제 동작에는 별도 권한 검사가
필요합니다. 잘못된 범위·ID·중복·잘못된 행은 거부하고 진짜 빈 결과만 null입니다.

## 트랜잭션 가드

순방향 마이그레이션 0064는 C3와 구분되는 테넌트·원본 종류·물리 ID 가드를 추가합니다.
정확한 범위와 READ COMMITTED가 필요하며 읽기 가드는 대기하지 않습니다. false이면 전체
트랜잭션을 롤백해야 합니다. 일부 가드를 유지한 채 계속하거나 다른 가드를 잡고 기다리면
안 됩니다. 응답은 엄격한 boolean이고 오류를 자동 재시도하지 않습니다.

필수 AFTER 행 트리거가 바인딩 생성·변경과 세션 생성·변경·허용된 삭제에 배타 가드를
획득합니다. 기존 BEFORE 검증과 행 잠금 순서를 유지합니다. 따라서 부재에서 생성, 권한
변경·비활성화, 인증에 따른 세션 사용 갱신, 철회, 기존 30일 보존 후 정리를 보호합니다.
읽기 가드가 유지되는 동안 쓰기는 변경을 커밋할 수 없습니다. 관련 세션·바인딩 가드를 모두
먼저 잡아야 하며 새로 발견된 관련 원본을 가드 없이 읽어서는 안 됩니다.

조회 자체는 트랜잭션 수명, 마이그레이션·복구 epoch, 전체 예산, 실패 오염 또는 가드 보유를
보증하지 않습니다. 향후 고정된 서버 합성기가 같은 클라이언트에서 전체 권한과 부재를
재검증하고 원자 게시까지 필요한 모든 가드를 유지해야 합니다. 가드 중 콘텐츠·키·네트워크
입출력이나 사람의 응답을 기다리지 않습니다. 종료된 읽기 트랜잭션은 게시 권한이 아닙니다.

## 남은 경계와 검증

런타임 역할에 함수 실행이나 테이블 읽기를 부여하지 않습니다. 실제 OIDC+CSRF, 설치·검토자
권한, 별도 서비스 게시자 인증, 전체 원본 closure, 예산, 전용 역할, 원자 결정·outbox,
복구, API·SDK, 기여자 통합 및 종료 감사는 남아 있습니다. 서비스 토큰 파일, 관리자 TRUNCATE,
복구 전체가 이 가드만으로 보호되는 것도 아닙니다.

역할 재프로비저닝은 새 함수 두 개의 복원된 PUBLIC 및 기존 관리 역할 직접 실행 권한을
회수합니다. 기존 복구 ACL 회귀 검사는 새 시그니처를 포함하고 모든 플랫폼 함수를 검사합니다.

[단위 검사](../../packages/postgres/src/postgres-release-oidc-sources.test.ts)는 제공된 클라이언트,
정확한 관측 및 잘못된 응답을 검증합니다.
[실제 PostgreSQL 검사](../../packages/postgres/src/postgres-release-oidc-sources.integration.test.ts)는
격리된 proofstack_test에서 비변경 조회·네이티브 시간·가드 대기·부재 생성·쓰기 롤백과 해제 후
완료·테넌트 및 종류 구분·범위와 격리 수준·권한 거부를 검사합니다. 운영 인증을 보증하지 않습니다.
