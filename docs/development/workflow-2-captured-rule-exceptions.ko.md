# 전체 보존 관측에 기반한 규칙 예외 정족수

[English](workflow-2-captured-rule-exceptions.md) | [한국어](workflow-2-captured-rule-exceptions.ko.md)

이 구현은 보존 자료의 자격·증거 합성이며 체크포인트 4는 미완료입니다.
[ADR-0050](../architecture/0050-resolve-complete-captured-rule-exception-quorums.md)과
[진입 감사](workflow-2-decision-entry-audit.ko.md)의 실제 인증·현재 원본·네이티브 게시 경계를 유지합니다.

## 원래 예외와 전체 이력

고정된 정상 승인·예외 진입점이 같은 전체 이력·자격 엔진을 사용합니다. 정상 승인의 API·오류·
결과 모양과 동작은 유지합니다. 예외는 원래 종류와 정규 다이제스트를 그대로 사용하며 일반
승인을 예외로 재해싱하지 않습니다. 실제 전체 주체·정책 규칙·설치 검토 요건은 고정 서버가
유도해야 합니다. 임의 기본 정족수·권한·유리한 최신 기록이나 matched 표시를 만들지 않습니다.

모든 행동·반대·상향 요청·기권·만료·철회·정확한 승계·경쟁 후속 기록과 현재 사용자·세션·
권한·검토자 이력을 보존합니다. 예외에서 후보·정책 작성자와 실제 평가자는 자신을 지지할 수
없고 평가자 출처가 불명확하면 불가용입니다. 기존 그룹 매칭으로 서로 다른 사람과 필수 사람
그룹을 검사하며 한 사람의 여러 소속을 여러 사람으로 세지 않습니다. 4,096명 한계를 유지합니다.
과거 로그인 자연 만료만으로 이미 기록한 행동을 철회하지 않지만 실제 철회·권한 변경·승인
만료는 계속 적용합니다. 새 행동의 인증이나 사람의 전문성을 입증하는 것은 아닙니다.

## 조건과 모든 보완 통제

원래 통제 참조마다 관측을 남깁니다. 비활성 기록이라도 관측 자체를 누락하면 전체가 불가용이고,
명시적 미검사에는 실제 만료·철회·승계 사실이 필요합니다. 찬성 행동을 비찬성으로 위장해 통제
검사를 생략할 수 없습니다. 현재 찬성 예외는 보존된 콘텐츠·네이티브 카탈로그 관측이 필요하며
미검사·검증 실패·변경·만료·불가용을 지지 근거로 사용하지 않습니다.

각 승인에서 따로 보면 일관돼도 같은 물리 아티팩트의 현재 카탈로그가 서로 다르면 전체는
불가용입니다. 미해결 조건·충돌·현재 반대·상향 요청은 유리한 자료 뒤로 숨기지 않습니다.
선택된 증인들의 실제 통제·승인·검토자 권한 만료 중 최솟값을 보존합니다. 보존된 바이트만으로
통제의 효과를 자동 입증하지 않습니다.

## 원래 예산과 게시 경계

전체 이력 합성이 승인과 전체 통제 관측을 깊은 해석·그룹화 전에 한 번 계상하고, 고정 내부
단계는 같은 정규 승인을 다시 검증하되 콘텐츠·카탈로그 투영만 계상합니다. 단독 통제 검사는
기존대로 자신의 원래 행도 계상합니다. 공개
생략 플래그·임의 콜백·새 예산은 없습니다. 실제 고정 서버가 원래 요청 예산과 실패·폐기·반복·
관계 조회를 포함한 모든 입출력 계상을 관리해야 합니다. 인스턴스나 분리된 보고서가 요청
바인딩·현재 권한을 증명하지 않습니다.

기존 규칙 분류는 알려진 예외 가능 위반만 별도로 해소하고 원래 평가 결과를 바꾸지 않습니다.
예외 불가 위반·불확정 증거·철회된 정책은 계속 차단하고 approval_required에는 별도 정상
승인이 필요합니다. 실제 OIDC·CSRF 또는 별도 게시자 인증, 설치 권한, 전체 현재 원본, 네이티브
cut·epoch·모든 가드를 원자 게시까지 검증하는 일은 남아 있습니다. 새 역할·권한·API·워커·배포를
추가하지 않습니다.

집중 검사는 출처·독립성·반대·조건·철회·승계·분기·기존 로그인 만료·행동 만료·통제 실패·
변조·상충 관측, 4,096명 전체와 마지막 필수 사람 그룹, 정확한 예산과 한 단위 부족, 기존 보수적
규칙 분류를 다룹니다. 대규모 예외 사례는 기존 정상 승인 대규모 사례의 30초 한계를 사용하고
기존 검사·자료 개수·커버리지·제품 제한은 변경하지 않습니다. 합성 공개 관측을 실제 제공자
권한이나 체크포인트 완료로 표현하지 않습니다.
