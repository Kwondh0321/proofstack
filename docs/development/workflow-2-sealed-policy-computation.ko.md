# 봉인된 정책 입력의 과거 시점 계산

Workflow 2 체크포인트 3은 아직 미완료입니다. `computeSealedPolicyEvaluation`은 소유 작업에
저장된 스냅샷 레코드와 완전한 정규 페이지로 계산하는 코어 함수입니다. 작업 등록, 워커 실행,
평가 결과 게시 기능은 포함하지 않습니다.

기대 범위·작업·원본 요청·스냅샷 식별자는 권한 있는 소유 작업에서 가져와야 합니다. API
호출자가 제공한 스냅샷 ID나 해시가 권한을 대신하지 않습니다. 기존 검증기로 전체 페이지,
정규 바이트, 매니페스트, 원본 루트 정의, 소스 증인과 버전이 고정된 closure를 확인합니다.
계산은 입력 스키마 0.2를 요구하며, 완전한 closure가 없는 과거 입력을 승격하지 않습니다.

권한·적용 조건의 루트 해시를 원본 증인에 연결하고, 수집 전후 후보 및 정책 생명주기 관찰이
안정적인지 확인합니다. 원본 후보와 정책에서 일곱 선택 조건을 다시 계산하며, 정책 유효
기간을 의미 시점의 정확한 정밀도로 별도 확인합니다. 승인은 항상
`indeterminate` / `approval_not_evaluated`로 남습니다.

논리 소스 키는 증인을 찾는 용도입니다. 루트 증인·권한 부모·필요한 기준 선택·평가 신뢰
부모는 정의 해시를 포함한 전체 원본 참조와 원본 본문 해시를 함께 보존해야 합니다.

후보의 소스 리비전·모델 선언·어댑터 확인 목록은 원본 대상·부모 해시·경로를 빠짐없이
보존해야 합니다. 참조 가용성은 실행 코드, 실제 제공자 측정 또는 검토자 전문성을
입증하지 않습니다. 결과는 `declared_reference_authority_only`와 과거 관찰 한계를 유지합니다.

규칙별 closure에 필요한 의미 검증, 미해결 선택자, 기준 집합의 승인 이력과 평가 신뢰
관찰을 확인한 뒤 엄격한 술어 계산을 수행합니다. 관련 없는 누락 증인은 전체 목록에
남습니다. 저장된 과거 관계 판정은 의미 검증을 대신하지 않습니다. 일곱 술어와 네 가지
결과를 원본 순서대로 보존하며 전체 안전 점수는 만들지 않습니다.

증인은 모든 원본 본문을 복사하지 않습니다. 이 계산은 권한 있는 봉인 과정이 생성한
의미·권한 투영을 검증하고 소비하며, 없는 원본 본문이나 누락된 관계를 복원하지 못합니다.
정상 봉인 관찰을 모델링한 단위 테스트는 수집·봉인·워커의 실제 서비스 승인을 뜻하지 않습니다.

남은 작업은 전체 작업 비용 계량, 메모리·공유 봉인 적합성, PostgreSQL 계산 시작, 별도
워커, 현재 fence를 보유한 결과·시도·작업·outbox 원자 게시, 권한 있는 결과 재계산,
API·SDK, 실행 중·완료 상태 복구 및 독립 종단 감사입니다. 과거 계산은 새로운 게시나
릴리스 권한이 아닙니다. 자세한 경계는 [영문 문서](workflow-2-sealed-policy-computation.md)에 있습니다.
