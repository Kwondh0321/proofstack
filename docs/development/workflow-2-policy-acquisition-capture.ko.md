# 정책 수집 경로의 소유 예산 확보

후속 [제한된 초기 소스 어댑터](workflow-2-policy-initial-sources.ko.md)는 정확한 열린 credit과
decoder 전 한도를 owning metadata 읽기에 연결합니다. 실제 worker 실행 연결은 남아 있으며
의미적 계량과 물리 transport 제한은 구별합니다.

Workflow 2 체크포인트 3은 아직 열려 있습니다. 내부 `sealPolicyEvaluationSnapshot`의
선택적 `acquisitionAdmission`으로 커밋된 예산 확보를 수집·봉인 경로에 연결합니다.
공개 API, worker 실행 파일 또는 운영 조합은 추가하지 않습니다.

서비스 토큰 실행 권한·범위·결정 시도의 fence를 먼저 확인합니다. 원래 요청과 작업을
검증하고 새 확보를 커밋한 뒤에만 소스 I/O를 시작합니다. 중복·모호한 응답·변조·만료는
새 수집을 허가하지 않습니다. 확보 호출 전부터 단조 시간을 측정해 응답 지연을 차감하고,
밀리초 미만의 남은 시간은 내림합니다. 원래 요청·해시·리스 기한은 바꾸지 않습니다.

남은 읽기·레코드·참조 수와 공유 바이트 한도를 별도 수집기에 적용합니다. 읽기와 미리
알려진 trace 요청 행은 I/O 전에, 가변 응답 행·JSON 바이트는 응답 시 제한합니다.
이는 응답 수용 제한이며 전송 디코더가 아닙니다. 실제 전송 비용·가변 목록의 전송 전
한도는 별도이며 체크포인트 종료 전 검증이 필요합니다.

시작한 메타데이터 읽기가 실패하거나 측정할 수 없으면 비용을 미확정으로 보존합니다.
형제 읽기와 거부된 호출까지 추적·종료를 기다린 뒤, 알려진 비용은 정확히 정산하고
미확정 비용은 확보량 전체를 차감합니다. 아티팩트 바이트·규칙 실행 비용은 환불하지 않습니다.

성공 경로에서는 작업과 소스 보호를 유지한 같은 DB 연결에서 정산·이력 추가·봉인을
순서대로 수행합니다. 다른 풀로 정산해 작업 잠금에 막히지 않도록 합니다. 중복·순서 오류·
만료한 포트와 호출자가 잡거나 기다리지 않은 오류도 트랜잭션 커밋을 막습니다.

보호된 수집·봉인이 끝나기 전에 외부 정리 로직이 실행되지 않도록 promise를 기다립니다.
콜백 반환만으로 커밋됐다고 판단하지 않습니다. 실제 트랜잭션 커밋 응답 뒤에만 확정합니다.
봉인이 실패하면 잠금을 해제한 뒤 별도로 비용을 정산하고 그 응답도 검증합니다. 실패가
겹치면 원래 오류와 정산 오류를 함께 보존하며, 모호한 응답을 자동 재시도하거나 환불하지 않습니다.

집중 검사와 실제 PostgreSQL 검증을 구분합니다. 기존 커버리지·기한 기준을 유지하며,
전체 전송 비용·공통 저장소 적합성·모든 상태의 복구·worker·API·SDK·기여자 검증과
독립 종료 감사가 남아 있습니다. 선택 항목 없는 기존 내부 호출은 영속 수집 비용
확보의 증거가 아닙니다.
