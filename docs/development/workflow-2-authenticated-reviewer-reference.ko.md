# 인증된 검토자 권한 관리 참조 구현

[English](workflow-2-authenticated-reviewer-reference.md) | [한국어](workflow-2-authenticated-reviewer-reference.ko.md)

상태: 체크포인트 4의 구성요소 선행 작업입니다. Workflow 2는 여전히 **3/7 체크포인트 승인**입니다.
[ADR-0061](../architecture/0061-retain-original-reviewer-administration-provenance.md),
[진입 감사](workflow-2-decision-entry-audit.ko.md),
[검토자 원본 저장소](workflow-2-native-reviewer-repository.ko.md)를 함께 읽으세요.

[PostgreSQL 관리자 구현](workflow-2-native-reviewer-administration.ko.md)은 별도 선택 역할,
제한된 정규화 읽기, 가드를 유지한 원자적 발행과 복구 경계를 구현합니다.

`ReleaseReviewerAdministrator`는 실제 사용자 자격 증명을 받는 고정 선언·수명주기 작업을 정의합니다.
워크스페이스 참조 구현은 기존 선택 관리와 같은 비공개 테넌트 상태를 사용합니다. 실제 OIDC 세션·변경
인증기가 생성된 쿠키와 CSRF, 정확한 범위, `approval:authority:manage`를 본문 해석 전에 확인합니다.
명시적 `synthetic_reference`이며 외부 IdP 로그인이나 실제 전문성을 입증하지 않습니다.

공개 의도에는 범위·발급자·행위자·시각·원본 영수증을 넣을 수 없습니다. 서버가 실제 인증에서 도출하며
검토자는 자신의 권한을 직접 발급할 수 없습니다. 기존 검토자 선언·수명주기 0.1과 정규 바이트는 보존합니다.
요청 상한 63 KiB는 기존 64 KiB 정의 안에서 서버 필드 여유를 확보합니다.

별도 reviewer-publication 0.1 도메인은 정확한 선언·이벤트, 전체 원본 해시, 관리자 영수증,
안전한 신원·권한·세션 해시 및 발급 시점을 연결합니다. 원상에는 쿠키·CSRF·비밀 검증값·근거 내용이 없습니다.
정의·권한·전체 자료 상한은 8 KiB/512 KiB/1 MiB입니다. 독립 Python 벡터는 유니코드와 원래 시각 정밀도를
검증합니다. 코어 검증은 원래 시점의 관리자 적격성을 확인하며 현재 인증·현재 발행 권한을 부여하지 않습니다.

실제 코어 검토자 저장소의 독립 분기에서 작업한 뒤 하나의 상태 비교·교체로 선언·원본 증명·두 정규 발행 의도를
함께 반영합니다. 중간 권한·세션·소스 변경은 전체 작업을 거부합니다. 자동 재시도나 범용 트랜잭션 콜백은 없습니다.
같은 요청 재시도에도 현재 인증이 필요하며 최초 행위자·요청·시각을 보존합니다. 원본 증명이 없는 과거 루트·부모·
종료 대상에 새 증명을 붙이지 않습니다. 반환값과 테스트 관찰은 독립 복사본입니다.

미확인·거절·검증 상태, 합성·운영자 검증 표시, 미래 효력과 충돌 선언을 보존합니다. 고정 대상은 설치·게이트·검토자이며
활성 선택을 새 선행 조건으로 만들지 않습니다. 관리자 인증은 전문성·대리 승인·현재 근거 내용 검증이 아닙니다.
이후 관리자 로그아웃이 기존 선언을 자동 폐기하지 않습니다. 실제 승인·결정은 현재 검토자 권한·종료 이력·근거를
별도로 검증해야 합니다.

구성요소의 정확한 커밋 전체 검증 뒤 별도 네이티브 관리자 역할·전진 마이그레이션·보유 가드·원자적 발행·복구를
구현합니다. 실제 승인·폐기, 결과 전 입력 계획, 완전한 결정 발행, API/OpenAPI/SDK, 실서비스 기여자 검사와
독립 종료 감사까지 체크포인트 4는 열려 있습니다. 이후 5–7과 측정 근거에 따른 5단계를 계속합니다.
