# 인증된 선택 게시 서비스의 메모리 참조와 공통 검증

[English](workflow-2-authenticated-selection-reference.md) | [한국어](workflow-2-authenticated-selection-reference.ko.md)

상태: 체크포인트 4의 참조 구현 선행 작업입니다. Workflow 2는 **7개 중 3개 승인** 상태이며,
이 구성요소도 정확한 소스의 로컬·원격 검증을 통과해야 합니다.
[ADR-0060](../architecture/0060-own-authenticated-memory-reference-state.md),
[네이티브 게시 가이드](workflow-2-authenticated-selection-publication.ko.md),
[진입 감사](workflow-2-decision-entry-audit.ko.md)를 함께 확인하세요.

`ReleaseSelectionInstaller`는 기존 네이티브 입력과 최초 응답을 유지합니다.
`@proofstack/identity/testing`의 `MemoryReleaseSelectionInstallerReference`는 자기 소유의 세션·권한
상태에 기존 인증기를 연결해 실제 생성한 합성 쿠키와 CSRF를 검증합니다. 요청 본문은 그 이후에
해석합니다. 호출자가 사용자나 인증 보고서를 제출해 게시 권한을 얻을 수 없습니다.

모드는 명시적으로 `synthetic_reference`입니다. 합성 권한·세션·자료 준비 메서드는 시험용
관리자 도구이며 공개 권한이나 외부 OIDC 검증, 실제 사람의 전문성·승인을 뜻하지 않습니다.
기존 절대·유휴 만료, 사용 횟수 포화, 명시적 취소 규칙과 세션 다이제스트의 유일성을 유지합니다.
원본 게시 기록에는 쿠키·CSRF·비밀 검증 값을 포함하지 않습니다.

테넌트마다 실제 메모리 정책·선택 저장소, 현재 인증 상태, 최초 게시 기록과 게시 이벤트를 한 상태로
소유합니다. 독립된 복제본에서 비동기 소유 자료 검증을 수행한 뒤, 처음 상태가 여전히 현재 상태일
때만 전체를 한 번에 교체합니다. 세션 사용·권한 변경·취소·자료 변경이 끼어들면 전부 거부하며
자동 재시도하지 않습니다. 서로 다른 테넌트는 독립적으로 진행합니다.

모든 선택 정책은 같은 최종 시각에 확인합니다. 전체 논리 대상·이전 버전·철회 대상을 검증하고,
과거 재시도는 현재 권한 확인 후에도 최초 사용자·요청·시각·인증 기록을 반환합니다. 반복 읽기,
부재, 전체 대상 목록과 이벤트 검증 비용을 같은 누적 예산에 포함합니다. 초과 시 일부 성공한
목록으로 게시하지 않습니다. 반환값을 변경해도 저장된 원본은 바뀌지 않습니다.

공통 사례를 실제 PostgreSQL과 메모리 구현 양쪽에서 실행합니다. 인증 전에 본문에 접근하는
잘못된 구현을 검출하는 음성 대조도 포함합니다. 메모리의 동시 변경·만료·취소·원본 및 이벤트 훼손·
충돌·예산 초과 검사와 네이티브의 권한·트리거·RLS·잠금 검사는 각 실행 근거를 구분합니다.
identity의 문장·분기·함수·라인 100% 커버리지 기준은 유지합니다.

이 참조는 재시작 시 상태를 잃습니다. 별도 네이티브 인증과 메모리 자료를 원자적으로 묶거나,
내구성·운영 준비를 증명하지 않습니다. `readSynthetic*`는 시험용 관리자 관측이며 공개 읽기 경로나
현재 릴리스 권한이 아닙니다. 앱 설정·DB 권한·마이그레이션·HTTP·SDK 기능은 추가하지 않습니다.
검토자 권한 관리, 실제 승인·취소, 결과 이전 입력 계획, 완전한 현재 권한과 결정 게시, API·SDK·
실서비스 기여자 흐름·별도 종료 감사를 마친 뒤 체크포인트 5–7과 측정 기반 5단계로 이어갑니다.
