# 봉인된 정책 계산의 PostgreSQL 실행 시작

Workflow 2 체크포인트 3은 아직 미완료입니다. 마이그레이션 0059와
`PostgresPolicyEvaluationJobWorkerRepository.startComputation`은 이미 봉인된 작업을
원래의 유효한 시도에서 `running`으로 전환합니다. 소스 수집, 술어 계산, 결과 게시,
워커 실행 파일은 이 작업에 포함되지 않습니다.

고정된 evaluator 전용 함수가 소유 작업을 잠근 뒤 정확한 범위·복구 epoch·worker·시도·
lease·fence·DB 만료와 영수증 순서를 확인합니다. 봉인 상태, 열린 계산 시도, 동일한
불변 요청에 연결된 실제 저장 스냅샷이 필요합니다. 스냅샷·시도·lease·기한·사용량은
보존하며 상태·버전·DB 갱신 영수증만 전환합니다. 마지막 이력 슬롯의 비용 소진 처리도 유지합니다.

상태 전환과 한 개의 `start_computation` 이력을 원자적으로 기록하고 정규 intent를
검증합니다. 지연된 트리거가 최종 커밋에서도 DB 시간 기준 fence를 다시 확인하며,
만료되면 전체 롤백합니다. 동시 시작은 하나만 통과하고, 중복·취소·미봉인·다른 범위·
오래된 실행 권한은 거부합니다. 봉인 후 재시도는 원래 스냅샷을 재사용합니다.

실행 권한은 별도 `policyEvaluator` 역할에만 부여합니다. API·정책 제어·정책 작성자·
상위 워커 역할에는 부여하지 않습니다. 포트는 호출자 시간이나 교체 스냅샷을 받지 않습니다.

코어 계산 시작 포트는 기존 운영용 메모리 어댑터와 분리돼 있습니다. 실제 메모리 스냅샷
저장과 공유 적합성 검증은 남은 작업이며, 없는 게시 기능을 mock으로 대신하지 않습니다.
[과거 입력 계산](workflow-2-sealed-policy-computation.ko.md)은 현재 실행 권한 및
결과 원자 게시와 별도입니다.

전체 작업 비용 계량, 결과·시도 종료·작업 완료·outbox 원자 게시, 권한 있는 결과 재계산,
메모리 공유 적합성, 별도 워커, 실행 중·완료 복구, API·SDK, 실제 서비스 기여자 검증과
독립 종료 감사가 남아 있습니다. 이 선행 구현만으로 체크포인트 완료를 선언하지 않습니다.
자세한 경계는 [영문 문서](workflow-2-policy-computation-admission.md)에 있습니다.
