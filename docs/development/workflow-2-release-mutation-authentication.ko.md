# 실제 소유 인증을 거치는 릴리스 변경 진입점

[English](workflow-2-release-mutation-authentication.md) | [한국어](workflow-2-release-mutation-authentication.ko.md)

[ADR-0051](../architecture/0051-bind-release-mutations-to-owning-authentication.md)과
[진입 감사](workflow-2-decision-entry-audit.ko.md)에 따른 인증 합성입니다. Workflow 2는 3/7개
체크포인트 승인 상태이며 실제 현재 권한과 네이티브 결정 게시는 미완료입니다.

## 별도 동작과 실제 자격증명

브라우저의 선택 관리·검토자 권한 관리·승인·결정 게시는 각각 고정 메서드를 사용합니다.
실제 OIDC 세션 조회와 그 세션에 연결된 CSRF를 검증한 뒤, 각각의 별도 capability와 정확한
테넌트·프로젝트·환경 범위를 검사합니다. admin 역할이나 다른 릴리스 권한은 대체물이 아닙니다.
요청은 사용자·인증 영수증·검토자 소속·검증 콜백을 지정할 수 없습니다. 범위 해석보다 인증을,
변경 본문·그래프 취득보다 capability·범위 검사를 먼저 수행해야 합니다.

비공개 서비스 게시자는 별도 진입점에서 실제 서비스 비밀값과 검증 후 사용 가능 여부를
확인합니다. 정책 워커 권한은 결정 게시 권한이 아닙니다. 서비스 경로를 사람의 승인이나
선택·검토자 권한 관리로 바꿀 수 없으며 개발 자격증명 우회 경로도 추가하지 않습니다.

## 프로세스 내부 인증 사실과 남은 게시 경계

결과는 비공개 WeakMap에 상태를 보관한 동결 불투명 객체입니다. 고정 소유 서비스는 정확한
동작·범위·원래 요청 ID로 이 객체를 검사하고 원래 사용자·영수증의 복사본을 받습니다. 요청 ID는
변경 본문이 아닌 소유 서버의 요청 문맥에서 전달합니다. 공개 영수증·사용자
객체·복사·프록시·JSON 복원으로는 인증 객체를 재현할 수 없습니다. 공개 필드와 반환 자료에
세션·CSRF 토큰이나 다이제스트, 서비스 비밀값·검증 해시는 포함하지 않습니다.

이는 신뢰된 서버 설정의 소유 인증을 완료했다는 사실입니다. 같은 서버 프로세스 안의 악성
코드를 격리하거나 검토자의 전문성·설치 권한·현재 게시 권한을 입증하지 않습니다. 재시작 후
복원할 자격증명이 아닙니다. 나중에 세션이 철회되어도 과거 인증 사실은 남지만 새 게시 권한은
별도로 현재 원본에서 검사해야 합니다.

고정 네이티브 소유자는 실제 불투명 객체와 현재 세션·사용자 권한·설치·검토자 권한, 전체
원래/현재 원본, migration·복구 epoch·유효기간을 검사하고 모든 가드를 원자 기록·정규 outbox
쓰기까지 유지해야 합니다. 분리된 보고서나 이전 인증 성공으로 이를 대체할 수 없습니다.
이번 변경은 DB 역할·권한·마이그레이션·공개 API·워커·배포를 추가하지 않습니다.

합성 소유 조회 fixture에서 실제 세션·CSRF 쌍과 해시된 서비스 비밀값을 사용해 권한·범위·
철회·위조·복원·반환 자료 변경·검증 중 서비스 철회·저장소 실패를 검사합니다. 기존 암호·인증
검사는 유지하며 실제 제공자 로그인이나 실제 사람의 릴리스 승인을 인증했다고 주장하지 않습니다.
