# 결정 권한 스냅샷 계약과 과거 자료 복원

[English](workflow-2-decision-authority-snapshot.md) | [한국어](workflow-2-decision-authority-snapshot.ko.md)

상태: 체크포인트 4의 계약 선행 작업입니다. Workflow 2는 3/7 완료이며 현재 검토자·게시자
권한, 저장소, 네이티브 원자적 게시, API/SDK와 독립 종료 감사는 남아 있습니다.
[ADR-0039](../architecture/0039-retain-bounded-decision-authority-material.md)와
[진입 감사](workflow-2-decision-entry-audit.ko.md)를 함께 읽습니다.
별도의 [0.2 현재 권한 자료](workflow-2-decision-current-authority-material.ko.md)는 기존 0.1 형식을
재해석하지 않고 완전한 원본 관측을 추가합니다.

## 원래 관측과 신원 경계

[자료 계약](../../packages/contracts/src/release-decision-authority-material.ts)은 원래 결정 입력,
DB 시각·복구 epoch, 게시자 영수증, 공개 신원·권한 관측, 후보, 관련 선택 버전 전체,
계획된 모든 정책·요청, 알려진 원래 평가 그래프, 승인·철회·원래 검토자 바인딩과 수명주기를
보존합니다. 누락·읽기 불가·무효 관측, 자문 정책과 지지하지 않는 승인도 생략하지 않습니다.
`complete` 표시는 캡처된 관측이며 실제 전체 행 열거를 증명하지 않습니다. 소유 도메인의
읽기·완전성·정의 해시·원래 봉인된 평가 근거 검증은 별도로 구현해야 합니다.

완료 그래프의 요청 본문, 작업, 닫힌 결정 실행 시도, 봉인 입력·결과 참조와 게시 영수증을
연결합니다. 재시도 작업자가 이전 worker/epoch의 봉인 입력을 재사용할 수 있으므로 원래
봉인 fence를 바꾸지 않습니다. DB 시각 정밀도와 기존 요청 생성의 밀리초 계약을 보존합니다.

공개 신원 자료에는 쿠키·세션·CSRF·토큰·검증용 비밀 해시·키·비공개 인증 증명을 넣지
않습니다. 원래 승인 바인딩을 새 로그인으로 대체할 수 없습니다. 공개 ID와 `active` 표시는
인증이 아니며 실제 현재 권한·만료·비공개 증명은 네이티브 경계에서 확인해야 합니다.
보존한 행·바이트는 동결 예산의 최소 사용량이며 반복·폐기한 관측의 비용도 차감해야 합니다.

## 정해진 크기의 전송과 검증

자료·헤더·페이지는 서로 다른 정규 인코딩 도메인을 사용합니다. 인코딩된 자료는 최대
64 MiB, 프레임은 2,048바이트, 페이지는 최대 128프레임입니다. 최대 헤더와 최대 페이지의
512 KiB 응답 한도를 검사합니다. 전체 순서·바이트 수·소유 참조·해시를 보존하며 프레임을
모두 합친 뒤 엄격한 UTF-8과 정규 바이트를 검증합니다.

[비공개 코덱](../../packages/core/src/release/release-decision-authority-snapshot.ts)은 원래
입력 해시, 기대한 범위·결정·헤더·페이지, 정확한 도메인·버전과 권한 보증 요약도 확인합니다.
합성 검토자 `synthetic_reference`와 읽기 불가 권한을 숨길 수 없습니다. 빈 보증 목록은
관측이 없다는 뜻이며 승인이 불필요하다는 증명이 아닙니다. 독립 Python 벡터와 여러 페이지,
UTF-8 경계, 잘못 연결된 완료 그래프, 해시를 다시 계산한 악성 자료를 검사합니다.

마이그레이션 0062는 사용자 권한 이름 세 개를 등록합니다. workload 위임과 기본 개발
신원에는 부여하지 않으며 새 역할·테이블·grant·게시 함수를 만들지 않습니다. 실제 운영
게시 권한이나 실제 사람의 전문성을 검증한 것으로 해석하지 않습니다.

[원본 소스 검사](workflow-2-decision-source-validation.ko.md)를 바탕으로 진행합니다.
다음 순서는 실제 현재 권한과 서로 다른 검토자 정족수, 메모리·네이티브 공통 검사,
한 연결에서 guard를 유지하는 그래프·결정·outbox 원자적 게시, 예약·복구, 제한된 API/SDK,
기여자 검증과 종료 감사입니다. 과거 자료 복원 결과로 나중 게시를 승인할 수 없습니다.
