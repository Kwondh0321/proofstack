# 개발 테스트 도구 보안 패치

[English](development-test-toolchain-patches.md) | [한국어](development-test-toolchain-patches.ko.md)

2026-10-23 한국 시간 기준 의존성 감사에서 개발 도구의 권고 8개를 확인했습니다.
Vite 8.2.2에 6개, `@vitest/mocker` 4.1.11에 2개이며 운영 의존성만의 감사는 0개였습니다.
개발 도구라는 이유로 낮은 심각도 감사 기준을 제외하지 않습니다. GitHub 푸시 요약의 별도 경고는
현재 연동의 조회 권한이 없어 HTTP 403을 반환했으므로 패키지 감사의 개수와 동일시하지 않습니다.
각 권고 링크와 영향 범위는 영문 문서에 보존합니다.

Vitest와 V8 커버리지 카탈로그를 함께 4.1.12로 올려 같은 mocker 패치를 사용합니다.
공개 패키지 메타데이터상 Vite 8과 호환되지만 일반 갱신은 기존 Vite 잠금을 유지했으므로
정확한 `vitest@4.1.12>vite` 경로만 8.2.4로 고정합니다. 다음 Vitest 변경 시 이 고정도 재검토합니다.
애플리케이션에 Vite 직접 의존성을 추가하거나 관계없는 소비자의 주 버전을 강제하지 않습니다.

공개 배포 메타데이터의 Node 호환 조건과 무결성 정보를 확인했습니다. 패치는 기존 1일 최소 배포
경과 기간보다 오래됐습니다. 엄격한 피어 검사·무결성 검증·고정 잠금 설치·커버리지·주장·전체 통합
검사를 유지하며 배포 기간 예외·권고 제외·스캐너 규칙 완화를 추가하지 않습니다.

고정 설치 후 운영 의존성과 전체 의존성 감사를 각각 통과해야 합니다. 실제 DB 검토자 검사로 새 실행기를
확인하고 정확한 최종 소스의 캐시 없는 전체 검사·호스팅 서비스 검사·CodeQL도 별도로 수행합니다.
중간에 의도적으로 중단한 검사는 통과가 아닙니다. 감사는 해당 시점의 알려진 권고에 대한 결과이며
미공개 취약점 부재나 체크포인트 완료를 보장하지 않습니다.
