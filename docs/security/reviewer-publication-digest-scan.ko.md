# 최초 검토자 발행 해시 탐지

[English](reviewer-publication-digest-scan.md) | [한국어](reviewer-publication-digest-scan.ko.md)

공식 배포물 체크섬을 확인한 Gitleaks 8.24.3은 구현 커밋
`ff86e15e601cee0da8063542e6dc6eddd683a35c`의 검토자 발행 벡터 `credentialSha256` 3곳을
탐지했습니다. 모두 합성 **안전한 공개 세션 상태 전체의 SHA-256**입니다. Python 정렬 키·압축
UTF-8 JSON으로 독립 재계산했고 실제 코어 픽스처와 독립 벡터 세 개도 일치합니다.
원상에는 식별자·범위·생성·만료·사용·폐기 정보가 있고 쿠키·CSRF·세션 비밀 해시·비밀번호
검증값·개인 키는 없습니다. 이 해시는 공개 상태 변조를 탐지하며 브라우저 인증을 하지 않습니다.

[.gitleaksignore](../../.gitleaksignore)에는 해당 불변 커밋·경로·규칙·줄의 정확한 지문 3개만
추가합니다. 기존 처리는 보존하며 전체 경로·규칙·값·후속 커밋을 제외하지 않습니다.
원본 벡터와 이력은 유지합니다. 탐지를 피하기 위한 값 분할·인코딩·이름 변경·재생성,
검사기 버전·규칙·범위·실패 종료 동작 변경은 없습니다.

전체 보존 이력은 최초 세 탐지로 실패했고 정확한 지문 처리 뒤 0개로 통과했습니다.
별도 일회용 로컬 저장소에서 같은 벡터를 새로 커밋한 대조 검사는 같은 ignore 파일로도
세 탐지를 모두 발견하며 실패했습니다. 새 탐지를 숨기지 않는다는 확인이며 모든 비밀정보를
탐지한다는 보장은 아닙니다. 보고서·로그는 완전 가림 처리하고 검토 출력에는 규칙·경로·줄·
개수만 남겼습니다.

이 검사로 정확한 커밋의 CI·CodeQL·네이티브 서비스·복구·종료 감사를 대신하지 않습니다.
검토자 관리는 열린 체크포인트 4의 구성요소입니다.
[참조 가이드](../development/workflow-2-authenticated-reviewer-reference.ko.md)를 함께 읽으세요.
