`a65458d6deccf13f01f161c42907e25de6a123f7`의 첫 CI 검사는 선택 게시 벡터와 실제 네이티브
응답 픽스처의 `credentialSha256` 10곳을 탐지했습니다. 모두 **비밀정보가 없는 공개 세션
상태 전체의 SHA-256**입니다. 쿠키·비밀값·세션 토큰 검증 해시·비밀번호 해시가 아닙니다.
공개 상태에는 식별자·범위·생성·만료·사용·철회 메타데이터가 있으며 실제 세션/CSRF 해시나
브라우저 자격증명은 없습니다. 이 해시는 해당 상태의 변조를 검출하며 세션 인증을 하지 않습니다.

각 값을 보관된 정규 원본에서 다시 계산했습니다. 벡터는 공유 합성 픽스처와 독립 Python
벡터로, 네이티브 값은 실제 완성 호출에 보관된 공개 상태 바이트로 확인했습니다. 탐지를
피하려고 값을 바꾸거나 분할·인코딩·재생성하지 않았습니다. 원래 네이티브 관측과 0.1
정규 바이트는 Git 이력으로 보존합니다. 준비 검사 질의가 바뀌면 새 실제 응답을 별도로
캡처하고 새 탐지도 같은 원본 재계산을 거쳐 새 커밋의 정확한 지문으로만 처리합니다.
0.1 의미 인코딩과 원래 계약 벡터는 유지합니다.

[.gitleaksignore](../../.gitleaksignore)에는 불변 커밋·파일·규칙·줄의 정확한 지문 10개만
추가합니다. 기존 [과거 합성 접두사 처리](historical-test-prefix-scan.ko.md)는 보존합니다.
전체 파일·규칙·값·새 커밋을 제외하지 않으며 검사기·규칙·검사 범위·실패 종료 코드를
바꾸지 않습니다. 최초 실패 증거와 Git 이력도 유지합니다.

공식 배포물의 체크섬을 확인한 Gitleaks 8.24.3으로 원래 10개 탐지를 재현했고 정확한
지문 처리 후 같은 범위는 0개였습니다. 별도 일회용 로컬 저장소에 같은 벡터를 새로
커밋한 대조 검사는 계속 2개를 탐지하며 실패했습니다. 새 탐지가 숨겨지지 않는다는
검증이며 모든 비밀값을 탐지한다는 보장은 아닙니다. 보고서·로그는 100% 가림 처리했고
검토 출력에는 규칙·경로·줄·개수만 남겼습니다.

원래 구현 SHA의 전체 로컬 검사는 패키지 테스트 18,007개, 실행기 16개와 캐시 없는
빌드 31개를 통과했습니다. 이 결과로 수정된 SHA의 CI·보안·실제 DB·종료 감사를 대신하지
않습니다. 별도로 드러난 기존 DB 목록·개수 오류도 C3 평가 범위를 유지하며 수정합니다.
