# ADR-0050: Resolve complete captured rule-exception quorums

Status: Accepted captured-data composition design. Owning current acquisition, actual private
authentication, native decision publication and checkpoint 4 remain open.

Date: 2026-10-16

## Context

Normal approvals already resolve complete captured histories and current reviewer/identity
observations. Exceptions need the same conservative census, with candidate/policy/evaluator
exclusions and every original compensating-control occurrence. Reinterpreting a normal approval
or accepting a caller's matched label would lose the original subject and authority boundary.

## Decision

Share the fixed census engine between two fixed operation wrappers. Keep the normal wrapper's
input, error class, result shape and behavior. The exception wrapper requires rule-exception
records and context; it never rehashes or relabels an ordinary approval. The owning composer must
derive the full original subject and installed reviewer requirement. No default exception quorum,
eligible role/group or authority is invented by this prerequisite.

Preserve every action, revocation, supersession, competing fork, original actor receipt, current
identity/grant/session and complete reviewer authority history. Exclude policy/candidate authors
and actual evaluators for exceptions. Unknown evaluator provenance remains unavailable. Count
unique eligible principals with the existing bounded group matcher and human-group requirements.
Opposition, escalation, conflicts and unresolved conditions cannot disappear behind positive rows.
Natural expiry of an old login alone does not revoke its original action; explicit revocation,
current grant/authority changes and action expiry retain their original meaning.

Retain every known control occurrence, including explicit skipped observations for inactive
records. Missing occurrences make the complete census unavailable. An affirmative active action
needs retained control observations; an earlier successful read cannot hide changed, expired or
unavailable native catalogs. Compare shared physical artifact catalog preimages across approvals,
even when each isolated control report is internally consistent. Include actual control expiry
when bounding selected supporting witnesses.

The owning census admits each original approval and whole control observation before deep control
parsing/grouping. Its fixed control pass revalidates the canonical record and admits retained
content/catalog projections on that same meter. The standalone inspector retains its existing
original-row admission. No caller-selected skip flag, callback,
new meter or favorable prefix is introduced. Actual owning I/O still needs its additional complete
attempt/relationship accounting, failure taint, lifetime and held native guards.

## Consequences

These are pure captured reports, not proof of current authority, control effectiveness or a native
waiver. The existing classifier still allows exceptions only for known waivable violations;
non-waivable violations, indeterminate evidence, withdrawn policies and normal approval prerequisites
remain conservative. Original outcomes and action definitions are unchanged. No role, grant,
migration, route, worker, signing operation or deployment is introduced.

Tests retain the unchanged normal census cases, exact exception scope/history/current-authority
counterexamples, all 4,096 admitted actors/control reports, the final required human group and exact
one-below aggregate quotas. The new large exception case uses the same explicit 30-second case
budget as the unchanged 4,096-person normal case; existing deadlines/assertions are unchanged.
