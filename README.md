# ProofStack

ProofStack is an open-source Agent Reliability Engineering platform for observing,
reproducing, evaluating, governing, and safely releasing AI agents.

> [!IMPORTANT]
> ProofStack is in its foundation phase. The repository currently prioritizes
> stable boundaries, explicit contracts, and verifiable engineering decisions over
> feature breadth.

## Project status

The first development phase establishes:

- the product constitution and architectural boundaries;
- a provider-neutral telemetry contract based on open standards;
- a minimal end-to-end trace ingestion path;
- repeatable local development, testing, and release foundations;
- secure defaults for data collection and multi-tenant operation.

No production-readiness claim is made before the documented release gates are met.
